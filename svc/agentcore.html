AgentCore

AI 组Serverless按用量自带跨 AZ 高可用

Bedrock AgentCore：把 AI 智能体推上生产的托管平台。Runtime 托管运行智能体（LangGraph、CrewAI、Strands 这些框架都能用），每个会话跑在单独的 microVM 里，按实际用的算力计费；Memory、Gateway、Identity、Observability 这些组件按需组合。

常见用法

客服助手、运维助手、能调业务接口的 AI 助理

为什么用它

智能体上生产要的运行隔离、会话记忆、工具网关、身份认证都托管好了，不用自己搭一套

核心知识点4 条

  1. Amazon Bedrock AgentCore：把智能体部署到生产、运维起来的托管服务，不挑框架（Strands Agents、LangGraph、CrewAI 等），也不挑模型
  2. Runtime：Serverless 地跑智能体，每个会话隔离，支持跑很久的任务
  3. Memory 管短期和长期记忆；Gateway 把现有的 API、Lambda 函数变成智能体能调的 MCP 工具；Identity 管智能体访问别的服务时的身份和凭证
  4. 另外有 Code Interpreter（沙箱里跑代码）、Browser（托管浏览器）、Observability（追踪和监控）

三个关键功能游戏里的三级升级，就是现实里的这三个功能

LV.1 · 第 1 级

Memory 记忆

短期记忆存这次会话的上下文，长期记忆跨会话记住用户的偏好和关键事实

游戏里：过路费提高

LV.2 · 第 2 级

Gateway 工具网关

把现有的 API、Lambda 函数接成 MCP 工具，智能体直接调业务接口

游戏里：这块过路费再 +20%

LV.3 · 第 3 级

Identity 身份

智能体有自己的身份：代用户调第三方服务时走 OAuth 授权，不用把密钥写进代码

游戏里：免疫「安全审计没过」
