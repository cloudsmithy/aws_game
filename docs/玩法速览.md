# 亚马逊云科技 User Group 云上大亨 · 玩法速览（简版）

三分钟看完就能开局。细节查「玩法手册」，全部规则和数字查「主持人规则书」。

> **免责声明**：游戏里特定亚马逊云科技生成式人工智能相关的服务仅在亚马逊云科技海外区域可用，亚马逊云科技 User Group 仅为帮助您了解行业前沿技术和发展海外业务选择推介该服务。亚马逊云科技中国区域相关云服务由西云数据和光环新网运营，具体信息以中国区域官网为准。游戏内价格为虚构，不代表实际定价；$ 是游戏币单位。

## 一、一句话

你是一家在亚马逊云科技上创业的公司：买服务，别人走到你的服务上就付你过路费；把服务升级、组成架构，收得更多；扛住线上事故，控制好账单。最后没破产的人赢，或者打满轮数按估值排名。玩法灵感来自经典的大富翁类桌游。

## 二、开局

1. 选人数（2–4 人）、模式、胜利条件，点「开始游戏」。人不够就勾「电脑」。
2. 每人随机抽一张角色卡：开局资金、能力、弱点、一个专属技能。开局页勾「三选一挑角色」的话，每人看 3 张挑一张。
3. 默认是标准局，第一次玩改选**入门局**，胜利条件保持默认（经典 + 15 轮上限，约 20 分钟）。

## 三、一回合

1. 掷两颗骰子往前走；掷出对子再掷一次。
2. 落到哪格结算哪格：没人买的服务可以买；别人的服务付过路费；自己的服务可以升级、加容量；卡牌格抽卡；账单格交钱。
3. 每次经过 Startup 扶持领 $200 Credits，同时交这一圈的运行费。
4. 踩到「Root 密钥泄露」或同一回合连掷 3 次对子，会被直接送进**维护窗口**：下回合二选一，付 $50 马上出来、照常掷骰子，或者停一轮再出来（传统企业上云要停 2 轮）。自己走到维护窗口那格也是停一轮或交 $50。
5. 可以出题考对手（同一回合只能发动一个）：花 $100 考一位对手（每局一次），答对他拿走这 $100，答错他赔你 $200；或者考全场（每 3 圈一次），每位对手各一道，每人 $50，答对的拿走、答错的赔你 $100。
6. 每走一圈可以花钱让对手抽一张 Health 卡一次：价钱是抽 re:Invent 卡的 1.5 倍，可以指定一位、随机一位，或者付两倍让每位对手各抽一张。

## 四、赚钱和花钱

服务越贵、升级越多、容量越大，过路费收得越多；集齐同色一整组，没升级的也翻倍。标准局、完整局、学习模式开局前 2 轮是新账户保护期，每笔过路费最多 $50。

凑齐一套真实架构（比如 ELB → EC2 → RDS），别人落在其中任意一块，按整套收。实例型服务空着也要交运行费，Serverless 没人用就不花钱。过路费每 5 轮涨一档，后期一块好地就能把人收破产。

## 五、防事故

抽到 Health 事件卡（AZ 断电、DDoS、证书过期……）会被罚。做了对应的高可用和安全功能就免疫，比如多 AZ 扛 AZ 断电、Auto Scaling 扛流量暴增、备份扛误删。

## 六、缺钱和破产

- 去掉升级、减容量：退一半；能停机的服务下线：先拿回买价一半周转，至少下线 3 轮才能还钱上线，下线期间别人落上来可以付原价拉走（娱乐模式不能下线）。
- 不要的服务整块卖回亚马逊云科技：实付按 8 折拿回。
- 全卖了也不够还才破产，服务按欠款比例分给各个债主。

## 七、专属技能

每个角色一个起死回生的技能，**总资产低于自己开局资金的一半**时，点「专属技能」发动，**一局一次**：先结算角色自己的技能，再「战略并购」：按卖回价买下总资产最高的对手的一块服务（钱付给他）。

## 八、模式和开关

| 选什么 | 一句话 |
|---|---|
| 娱乐模式 | 常用服务 + 盲盒格，抽卡最多，10 轮 |
| 入门局 | 只有基础规则，先熟悉 |
| 标准局 | 加技术债和季度财报，认真算账 |
| 完整局 | 加主动行动、完整交易（保留卡和标记也能换）、Savings Plans / RI |
| 学习模式 | 必答题、错题本，不限轮数 |
| 地狱模式 | 全部加压拉满，必须答题 |
| 高速部署（开关） | 部署点数 0–12，花点数发动 12 个技能，12 点能 DDoS 对手 |
| 代理商模式（开关） | 座位可以当代理商，拿货打折、转售、赚运行费差价 |
| 边玩边答题（开关） | 答对过路费减半、买服务打 8 折 |

## 九、三条建议

- 别把钱花光：每圈都要交运行费，现金太少一次没付上就被迫变卖。
- 先做多 AZ：最划算的第一笔防护。
- 先凑整组和架构：收得最多的方式。
