# Amazon Web Services User Group クラウドタイクーン · 遊び方クイックガイド（簡易版）

3 分で読めばすぐにゲームを始められます。詳しくは「遊び方マニュアル」を、すべてのルールと数字は「主持人规则书.pdf」（進行役用ルールブック）を見てください。

> **免責事項**：ゲームに登場する Amazon Web Services の生成 AI 関連の特定のサービスは、Amazon Web Services の中国本土以外のリージョンでのみ利用できます。Amazon Web Services User Group は、業界の最先端技術を知り、海外ビジネスを展開するお手伝いをする目的に限って、これらのサービスを紹介しています。Amazon Web Services の中国リージョンのクラウドサービスは西雲数据（NWCD）と光環新網（Sinnet）が運営しています。詳細は中国リージョンの公式サイトをご確認ください（公式サイトの記載が優先されます）。ゲーム内の価格は架空のもので、実際の料金を示すものではありません。$ はゲーム内通貨の単位です。

## 1. ひとことで

あなたは Amazon Web Services で起業した会社です：サービスを買い、ほかの人があなたのサービスに止まったら通行料を受け取ります。サービスをアップグレードしてアーキテクチャを完成させれば、もっと稼げます。本番障害を乗り切り、請求をうまく抑えましょう。最後まで破産しなかった人が勝ち、またはラウンド数の上限まで終えたら評価額で順位を決めます。ゲームのしくみは、定番のモノポリー系ボードゲームから着想を得ています。

## 2. ゲームの準備

1. 人数（2–4 人）、モード、勝利条件を選んで「ゲーム開始」をクリックします。人数が足りなければ「CPU」にチェックを入れます。
2. 各プレイヤーはロールカードをランダムに 1 枚引きます：初期資金、能力、弱点、固有スキル 1 つが書かれています。スタート画面で「3 枚からロールを選ぶ」にチェックを入れた場合は、各自 3 枚を見て 1 枚を選びます。
3. 初期設定はスタンダードです。初めてのときは**入門**に変え、勝利条件は初期設定のまま（クラシック + 15 ラウンド上限、約 20 分）にしましょう。

## 3. 1 ターンの流れ

1. サイコロを 2 個振って進みます。ゾロ目が出たらもう一度振ります。
2. 止まったマスの処理をします：誰も持っていないサービスは購入でき、ほかの人のサービスなら通行料を支払い、自分のサービスならアップグレードやキャパシティの追加ができます。カードマスではカードを引き、請求マスではお金を払います。
3. Startup クレジットを通過するたびに $200 のクレジットを受け取り、同時にその周の運用コストを支払います。
4. 「ルートキー漏えい」に止まるか、同じターンに 3 回続けてゾロ目を出すと、そのまま**メンテナンスウィンドウ**に送られます：次のターンに 2 つから選びます。$50 を払ってすぐに出て通常どおりサイコロを振るか、1 ラウンド休んでから出ます（クラウド移行中の老舗企業は 2 ラウンド休み）。自分で進んでメンテナンスウィンドウのマスに止まった場合も、1 ラウンド休むか $50 を払います。
5. 対戦相手に出題できます（1 ターンにどちらか 1 つだけ）：$100 を払って対戦相手 1 人に出題すると（1 ゲームに 1 回）、正解ならその人がこの $100 を受け取り、不正解ならその人があなたに $200 を支払います。または全員に出題すると（3 周に 1 回）、対戦相手 1 人につき 1 問、1 人 $50 で、正解した人はそれを受け取り、不正解の人はあなたに $100 を支払います。
6. 1 周に 1 回、お金を払って対戦相手に Health カードを 1 枚引かせられます：料金は re:Invent カードを引く料金の 1.5 倍です。相手を 1 人指定するか、ランダムに 1 人選ぶか、2 倍払って対戦相手全員に 1 枚ずつ引かせます。

## 4. お金の稼ぎ方と使い方

サービスが高いほど、アップグレードが多いほど、キャパシティが大きいほど、受け取れる通行料は増えます。同じ色のカラーグループをそろえると、アップグレードしていないサービスの通行料も 2 倍になります。スタンダード、フルゲーム、学習モードでは最初の 2 ラウンドが新規アカウント保護期間で、通行料は 1 回あたり最大 $50 です。

現実に使われているアーキテクチャ（たとえば ELB → EC2 → RDS）をそろえると、ほかの人がそのどれか 1 つに止まったとき、アーキテクチャ全体でまとめて請求できます。インスタンス型のサービスは使われていなくても運用コストがかかり、サーバーレスは使われなければお金がかかりません。通行料は 5 ラウンドごとに 1 段階上がり、終盤には良いマスが 1 つあるだけで相手を破産させられます。

## 5. 事故を防ぐ

Health イベントカード（AZ の停電、DDoS、証明書の期限切れ…）を引くとペナルティを受けます。対応する高可用性やセキュリティの機能を用意しておけば無効化できます。たとえばマルチ AZ は AZ の停電に、Auto Scaling はトラフィック急増に、バックアップは誤削除に耐えます。

## 6. お金が足りないときと破産

- アップグレードを外す、キャパシティを減らす：半額が戻ります。停止できるサービスをオフラインにする：まず購入価格の半分が戻って資金繰りに使えます。最低 3 ラウンドはオフラインのままで、その後お金を返せばオンラインに戻せます。オフラインの間にほかの人が止まった場合、定価を払えば持っていけます（パーティーモードではオフラインにできません）。
- 不要なサービスは丸ごと Amazon Web Services に売り戻せます：実際に払った額の 80% が戻ります。
- すべて売っても返しきれないときに初めて破産となり、サービスは借金の割合に応じて各債権者に分配されます。

## 7. 固有スキル

どのロールにも起死回生のスキルが 1 つあります。**総資産が自分の初期資金の半分を下回った**とき、「固有スキル」をクリックして発動します。**1 ゲームに 1 回**です：まずロール自身のスキルを処理し、続いて「戦略的買収」で、総資産がいちばん多い対戦相手のサービスを 1 つ売り戻し価格で買い取ります（代金はその相手に支払います）。

## 8. モードとスイッチ

| 選ぶもの | ひとことで |
|---|---|
| パーティーモード | よく使うサービス + ミステリーボックスのマス。カードをいちばん多く引けます。10 ラウンド |
| 入門 | 基本ルールだけ。まずはここで慣れましょう |
| スタンダード | 技術的負債と四半期決算が加わり、しっかりお金の計算をします |
| フルゲーム | アクション、すべての取引（手元に残したカードやマーカーも交換できます）、Savings Plans / RI が加わります |
| 学習モード | クイズ必須、間違いノートあり、ラウンド数無制限 |
| 地獄モード | すべてが最大の厳しさ、クイズ必須 |
| 高速デプロイ（スイッチ） | デプロイポイント 0–12。ポイントを使って 12 種類のスキルを発動でき、12 ポイントで対戦相手に DDoS を仕掛けられます |
| リセラーモード（スイッチ） | 席をリセラーにできます。割引価格で仕入れて転売し、運用コストの差額で稼ぎます |
| クイズしながらプレイ（スイッチ） | 正解すると通行料が半額、サービスの購入が 20%オフ |

## 9. 3 つのアドバイス

- お金を使い切らないこと：毎周運用コストがかかり、現金が少なすぎて一度でも払えないと売却を迫られます。
- まずはマルチ AZ：いちばんお得な最初の防御です。
- カラーグループとアーキテクチャを優先してそろえる：いちばん稼げる方法です。
