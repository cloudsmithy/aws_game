## 写法
- 说明、规则、卡牌、对话框、提示用です・ます；按钮、标签、标题用简短的名词或动词原形（サイコロを振る、購入、閉じる）；对局日志（棋盘上发生的事）用简短的常体或体言止め（ハンおじさんが S3 を購入），原文句末没有「。」就不加。
- 标点：，→「、」；。→「。」；：→「：」；；→「。」或「、」；（）→ 全角（）；「」『』照用；！？用全角；……→「…」。不要留中文的「，」「；」。
- 空格：拉丁字母、数字、`$` 金额和日文之间按原文留半角空格（S3 を購入、$200 を支払う），日文词语之间不加空格。
- `{$0}`、`{$1}`… 是占位符（运行时换成名字、数字、HTML），每个都要原样出现一次，可以调换顺序。
- HTML 标签和属性原样保留，只翻 title、aria-label、placeholder、alt 的值；class、id、onclick、style、href、src、data-* 都不动。文件名和链接不翻（比如 `../更新说明.html`）。
- `$` 金额、数字、`×`、`%`、`→ ← ⇄`、`+`、`\n` 原样保留。
- 原文开头或结尾有空格，译文同样留空格（这一段会和别的字拼在一起）。
- 架构流程（代码会解析）：→ ⇄ ← 和「 + 」原样、顺序不变；（可选）→（オプション），（可选：…）→（オプション：…），用全角括号；分句的「；」写成「。」；每一步以服务名开头（Lambda がサムネイルを生成）。
- 搜索别名（SVC_ALIAS，逗号分隔）：格式不变，中文别名换成日本人会搜的词（オブジェクトストレージ、サーバーレス…），英文的照留。
- 量词「块」「个」「张」按日语习惯（3 つのサービス、カード 2 枚），不硬翻。
