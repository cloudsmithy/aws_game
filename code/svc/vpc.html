SERVICE网络组 · 托管服务

VPC

网络组托管服务免费自带跨 AZ 高可用万能服务

你在云上的私有网络：自己划网段、子网、路由表和安全组，决定哪些资源能访问公网。VPC 本身不收费。

常见用法

把对外的负载均衡放公有子网，应用和数据库放私有子网

为什么用它

把资源放进自己的私有网络，子网和安全组决定谁能访问，数据库不用暴露在公网上

核心知识点5 条

  1. 自己的私有网络：选一段 CIDR，按 AZ 划子网；公有子网的路由表指向互联网网关
  2. 私有子网要出公网走 NAT 网关（放在公有子网里，按小时和流量收费）
  3. 安全组：实例级、有状态、只有允许规则；网络 ACL：子网级、无状态、有允许也有拒绝
  4. VPC 终端节点让流量不出公网：网关终端节点（S3、DynamoDB，免费）和接口终端节点（PrivateLink，大多数服务都有）
  5. VPC 之间用对等连接或 Transit Gateway 打通；VPC 流日志记录进出的流量

三个关键功能游戏里的三级升级，就是现实里的这三个功能

LV.1 · 第 1 级

私有子网 + NAT

实例不直接暴露在公网，也不用付公网 IPv4 地址费（2024 年起按小时收），出网走 NAT 网关

游戏里：实例放进私有子网（要开 NAT 网关，多交钱）

运行费：每圈 $20

LV.2 · 第 2 级

Session Manager

不开 22 端口、不用跳板机，也能登录私有子网里的实例，操作全程有记录

游戏里：配合私有子网，不开 22 端口，免疫 SSH 暴力破解

运行费：每圈 $20

LV.3 · 第 3 级

Transit Gateway

把多个 VPC 和公司机房连成一张网

游戏里：这块过路费再 +20%

运行费：每圈 $20

基础检测开启即可，不用自己部署采集；运行时监控要装代理，可以自动管理
3.私有子网中已连接 VPC 的 Lambda 函数需要调用 Secrets Manager。该 VPC 没有互联网网关和 NAT 网关，安全策略也禁止流量经过互联网。应该怎么做？SAA-C03
答案为 Secrets Manager 创建接口 VPC 终端节点
Secrets Manager 支持通过接口终端节点（PrivateLink）在 VPC 内私有访问，不需要互联网网关或 NAT。网关终端节点只支持 S3 和 DynamoDB；NAT 网关会让流量出互联网；VPC 对等连接不支持传递路由，无法借用对方的出口。　官方文档 ↗
4.某企业有 40 个 VPC 和一条到本地数据中心的 VPN 连接。要求集中互联，所有 VPC 都能访问本地网络，但开发 VPC 与生产 VPC 之间必须网络隔离。哪种方案运维开销最少？SAA-C03
答案用 Transit Gateway，开发和生产 VPC 关联不同的路由表
Transit Gateway 作为中心枢纽连接 VPC 和 VPN，可通过多个路由表把网络划分为相互隔离的路由域。全网状对等连接数量庞大，难以管理；VPC 对等不支持传递路由，无法经中转 VPC 访问本地；经互联网访问不满足私有互联要求。　官方文档 ↗
5.某公司通过一条 Direct Connect 连接访问 VPC。业务要求 Direct Connect 中断时仍能保持连通，但预算有限，可以接受备用链路的可靠性和性能较低。最具成本效益的做法是？SAA-C03
答案配置 Site-to-Site VPN 作为备份连接
Site-to-Site VPN 通过互联网建立 IPsec 隧道，可作为 Direct Connect 的低成本备份，代价是可靠性和性能较低。多位置多条专用连接弹性最高，但成本也最高；VPC 对等只能连接 VPC，接不进本地数据中心；NAT 网关只做地址转换，本身不是一条线路，流量到本地照样要走 VPN 或 Direct Connect。　官方文档 ↗
6.关于 VPC 中的安全组和网络 ACL，以下哪种说法正确？CLF-C02
答案安全组有状态、返回流量自动放行；网络 ACL 无状态
安全组有状态，返回流量自动放行；网络 ACL 无状态，返回流量需要显式允许。官方建议以安全组为主要控制手段，网络 ACL 作为子网级的辅助控制。　官方文档 ↗
7.私有子网中的 EC2 实例每月通过 NAT 网关向同一区域的 Amazon S3 传输数十 TB 数据，NAT 网关的数据处理费用很高。如何在实例保持私有的前提下最有效地降低成本？SAA-C03
答案为 S3 创建网关 VPC 终端节点，并加到私有子网的路由表
S3 网关终端节点通过路由表把流量直接导向 S3，不经过 NAT 网关，使用网关终端节点也没有额外费用。NAT 实例需要自行运维且存在单点问题；移到公有子网违反私有要求；Transfer Acceleration 用于加速远距离传输，降低不了 NAT 费用。　官方文档 ↗
