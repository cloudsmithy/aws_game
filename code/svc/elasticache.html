服务知识点/数据库组/ElastiCache

SERVICE数据库组 · PaaS

ElastiCache

数据库组PaaS按小时要自己做多 AZ

托管的内存缓存：Valkey、Redis OSS、Memcached，读写在微秒到毫秒级，挡在数据库前面扛热点读。

常见用法

缓存热点数据、会话、排行榜

为什么用它

同样的数据被反复读时放一层内存缓存：亚毫秒返回，数据库压力小很多

核心知识点5 条

  1. 托管的内存数据库，引擎有 Valkey、Redis OSS、Memcached
  2. 常见用法：缓存热点数据（先查缓存，没命中再查数据库）、会话存储、排行榜、计数器
  3. Valkey 和 Redis OSS 支持副本、多 AZ 自动故障切换、数据持久化；Memcached 只做简单缓存，不持久化
  4. ElastiCache Serverless 不用选节点规格，按用量计费
  5. 缓存要设过期时间，数据库改了以后要让对应的缓存失效

和谁比、怎么选

DynamoDB 还是 ElastiCache

推荐结果要持久保存、按用户查，选 DynamoDB；要亚毫秒延迟、丢了能重算，选 ElastiCache
