服务知识点/网络组/ELB

SERVICE网络组 · 托管服务

ELB

网络组托管服务按小时自带跨 AZ 高可用

负载均衡：把流量分给后面多台 EC2、容器或 Lambda，自动绕开不健康的；ALB 处理 HTTP/HTTPS，NLB 处理 TCP/UDP。

常见用法

网站和 API 的统一入口、多 AZ 高可用

为什么用它

多台后端前面放一个统一入口：自动分流量、绕开坏掉的实例，天生跨 AZ

核心知识点5 条

  1. 主要三种：ALB（七层，按路径、主机名转发 HTTP 和 HTTPS）、NLB（四层 TCP 和 UDP，延迟低、能给固定 IP）、GWLB（串接第三方安全设备）
  2. 健康检查自动把流量从坏掉的目标挪走；负载均衡器本身跨多个 AZ
  3. ALB 能挂 WAF、对接 Cognito 登录、卸载 TLS（证书用 ACM 免费签）
  4. 和 Auto Scaling 组配合：新起来的实例自动注册进目标组
  5. 按小时加容量单位（LCU）计费

三个关键功能游戏里的三级升级，就是现实里的这三个功能

LV.1 · 第 1 级

HTTPS + ACM

用 ACM 免费证书开 HTTPS，证书自动续期

游戏里：免疫证书过期

LV.2 · 第 2 级

LCU 预留

提前预留负载均衡器容量单位（LCU），接得住可预期的流量高峰

游戏里：性能效率支柱 +1 分

LV.3 · 第 3 级

负载均衡 + Auto Scaling

目标组挂在 EC2 Auto Scaling 组上：健康检查发现坏实例，Auto Scaling 自动换一台新的；流量高了按每个目标的请求数自动加机器

游戏里：你的 EC2 免疫「EC2 实例硬件退役」和「单点故障」（坏实例自动换掉）

和谁比、怎么选

CloudFront 还是 ELB

全球用户、静态内容多，Shield 挂在 CloudFront 上；只在一个区域、动态请求为主，挂在 ALB 上

1.ALB 工作在哪一层？
答案第 7 层（HTTP/HTTPS）
ALB 是 7 层，NLB 是 4 层
2.WAF 可以挂在哪些服务前面？
答案CloudFront、ALB、API Gateway
WAF 管第 7 层；API Gateway 只能挂 REST API，另外还能挂 AppSync、Cognito 用户池等
3.一个面向公众的网站部署在 Application Load Balancer 之后。最近发现个别 IP 地址在短时间内发送大量 HTTP 请求刷接口。如何以最少的运维工作量自动限制这些 IP？SAA-C03
答案为 ALB 关联 WAF Web ACL，并添加基于速率的规则
WAF 基于速率的规则按 IP 等维度统计请求，超过阈值时自动限流，无需人工维护名单。安全组只支持允许规则；NLB 工作在第 4 层，识别不了 HTTP 层的滥用；人工分析流日志再改网络 ACL 反应慢且运维开销大。　官方文档 ↗
4.某 Web 应用运行在单个可用区的 3 台 EC2 实例上，前面是 ALB。曾出现应用进程卡死而 EC2 状态检查仍然正常的情况，导致部分请求失败。如何既提升可用区级弹性，又能自动替换不健康的实例？SAA-C03
答案Auto Scaling 组跨多个可用区，并启用 ELB 运行状况检查
跨多个可用区的 Auto Scaling 组可在某个可用区故障时维持容量；启用 ELB 运行状况检查后，应用层不健康的实例也会被自动替换。更大的实例消除不了单可用区风险；EC2 状态检查发现不了应用层故障，仅告警还需人工处理；简单路由不做运行状况检查。　官方文档 ↗
5.某公司把单体应用拆成多个微服务，希望用同一个域名，根据 URL 路径（如 /api/orders、/api/users）把 HTTP 请求转发到不同的目标组。应使用哪种负载均衡器？SAA-C03
答案Application Load Balancer，配置基于路径条件的侦听器规则
ALB 工作在第 7 层，侦听器规则支持 path-pattern 条件，可按 URL 路径路由到不同目标组。NLB 工作在第 4 层，看不到 URL 路径；Gateway Load Balancer 用于部署第三方虚拟网络设备；多个 CLB 和域名不满足同一域名的要求。　官方文档 ↗
6.某实时多人游戏使用自定义 UDP 协议，需要承载每秒数百万请求并保持极低延迟，还要为每个可用区提供固定 IP 地址，方便客户加入防火墙允许列表。应选择哪种负载均衡器？SAA-C03
答案Network Load Balancer，每个子网关联一个弹性 IP
NLB 工作在第 4 层，支持 UDP，可处理每秒数百万请求，并为每个可用区提供静态 IP，面向互联网时可关联弹性 IP。ALB 面向 HTTP/HTTPS，不支持 UDP；CLB 只支持 HTTP、HTTPS、TCP 和 SSL；手工登记实例 IP 无法跟随伸缩自动更新。　官方文档 ↗
7.运维团队希望用一份模板描述 EC2、负载均衡器和数据库等资源，然后一键重复创建相同的环境（基础设施即代码）。应使用哪项服务？CLF-C02
答案CloudFormation
CloudFormation 让你用模板描述所需资源，由它负责预置和配置，创建的资源集合称为堆栈。Cost Explorer 用来分析费用，不能创建资源。　官方文档 ↗
