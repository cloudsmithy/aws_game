服务知识点/存储组/EBS

SERVICE存储组 · IaaS

EBS

存储组IaaS按小时永远单 AZ

给 EC2 用的块存储（云硬盘）：一块卷挂在同一个 AZ 的实例上当系统盘或数据盘，可以打快照备份。卷只在一个 AZ 里。

常见用法

系统盘、自建数据库的数据盘

为什么用它

要低延迟、像本地硬盘一样的块存储时用它，快照按增量备份

核心知识点5 条

  1. 块存储，挂在同一个 AZ 里的 EC2 上，像本地硬盘；卷只在一个 AZ 里，换 AZ 要靠快照
  2. 快照是增量的，存在 S3 里（看不到这个桶）；能跨区域复制，在别的 AZ 或 Region 恢复
  3. 卷类型：gp3（通用 SSD，性能和容量分开配）、io2 Block Express（高 IOPS 的数据库盘）、st1 和 sc1（吞吐型 HDD）
  4. 大多数卷同一时间只挂一台实例；io1、io2 支持多重挂载（Multi-Attach），同一个 AZ 里挂多台
  5. 用 KMS 加密，可以设成账户默认加密；快照锁定能让快照在到期前删不掉

三个关键功能游戏里的三级升级，就是现实里的这三个功能

1.EFS 和 EBS 最大的区别是？
答案EFS 能被多台实例同时挂载，EBS 卷一般只挂一台
EBS 有多重挂载，但只限部分卷类型和同一个 AZ
2.一块 EBS 卷存在于什么范围内？
答案单个 AZ
所以要靠快照才能在别的 AZ 恢复
3.EBS gp3 相比 gp2 的主要优势是？
答案IOPS 和吞吐能单独配，还更便宜
gp2 的性能跟容量绑定，还靠突发积分冲高；gp3 不用突发积分
4.EC2 实例 Stop 之后还收什么钱？
答案EBS 卷存储费和弹性 IP 费
停机只停算力费用，存储照收
5.一个运行在 Nitro 实例上的关键 OLTP 数据库需要单卷持续提供 200,000 IOPS 和亚毫秒级延迟。应选择哪种 Amazon EBS 卷类型？SAA-C03
答案预置 IOPS SSD（io2 Block Express）
io2 Block Express 挂载到 Nitro 实例时单卷最高可预置 256,000 IOPS，并提供稳定的亚毫秒级延迟。gp3 单卷最多 80,000 IOPS；st1 和 sc1 是面向顺序吞吐的 HDD，不适合随机 IOPS 密集型负载。　官方文档 ↗
