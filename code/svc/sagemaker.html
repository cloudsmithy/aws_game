1.SageMaker AI 把模型部署成实时推理服务，叫什么？
答案终端节点（Endpoint）
也支持异步推理和批量转换
2.默认配置下，SageMaker AI 实时推理端点没流量时也收钱吗？
答案收，实例一直开着
按实例小时计费。流量少可以用 Serverless 或异步推理；托管推理组件的端点也能缩到 0 个实例
3.SageMaker HyperPod 主要用来做什么？
答案大规模分布式训练，节点坏了自动换
训练基础模型动辄几周，节点故障自动恢复很重要
4.数据科学家在 Amazon SageMaker Studio 中工作，想浏览各模型中心的预训练模型，并直接对选中的模型进行微调、部署或评估。应使用哪项功能？AIF-C01
答案Amazon SageMaker JumpStart
JumpStart 提供大量预训练模型、解决方案模板和示例笔记本，可在 Studio 的 Models 页面中对模型进行微调、部署和评估。Model Monitor 用于生产监控，Clarify 用于偏差与可解释性，Ground Truth 用于数据标注。　官方文档 ↗
5.某公司每晚需要用已训练好的模型对一个很大的数据集统一打分，白天不需要任何在线预测。使用 Amazon SageMaker AI 时，哪种推理方式最合适？AIF-C01
答案批量转换（batch transform），无需常驻的推理终端节点
官方文档说明，批量转换适合对大型数据集做推理、且不需要持久终端节点的场景；实时推理适用于需要低延迟交互式响应的工作负载。　官方文档 ↗
6.一家金融公司正在开发贷款审批模型，既要检查训练数据中某些群体的样本数量是否明显偏少，又要说明每个特征对单笔预测的贡献。哪个亚马逊云科技工具专门提供这两类能力？AIF-C01
答案Amazon SageMaker Clarify
Clarify 可以计算训练前偏差指标（如类别不平衡 CI），并基于 Shapley 值给出特征归因来解释预测。注意：官方文档显示 Clarify 已不再向新客户开放，现有客户可继续使用。　官方文档 ↗
7.一个已上线的信用评分模型，团队担心随着线上数据变化，模型预测会逐渐出现偏差漂移，准确率也会下降，希望出现偏离时自动告警。应使用哪项功能？AIF-C01
答案Amazon SageMaker Model Monitor
Model Monitor 可持续监控生产模型的数据质量、模型质量、偏差漂移和特征归因漂移，并在出现偏离时告警。注意：官方文档显示 Model Monitor 已不再向新客户开放，现有客户可继续使用。　官方文档 ↗
