一回合

  1. 1 号位先走，第 2、3、4 位开局多领 $50 / $100 / $150（不算进开局资金）。
  2. 掷两颗骰子往前走；对子再掷一次，同一回合第 3 次对子进维护窗口。
  3. 结算落点：买服务 / 付过路费 / 抽卡 / 交账单；落在自己的服务上：加功能、加容量、FIS 攻击对手，
  • 三选一，之后可以「同色跳」。
  1. 掷骰子前后都能：花总资产 4% 抽 re:Invent 卡；每圈花 1.5 倍让对手抽 Health 卡；出题考一人（每局一次）或全场（每 3 圈）；资产管理、交易。

买服务

  • 按需：原价，稳。
  • Spot（只有 EC2、ECS、EKS、SageMaker AI）：出价保密，最低 20%；别人猜的价多出原价 10% 才抢得走。
  • 不买就留在亚马逊云科技，别人不能竞价抢。

缺钱怎么办

  • 去掉升级、减容量：退实付的一半。下线（EC2、RDS、Aurora、Redshift、ECS）：拿回买价一半，不收过路费；至少 3 轮后还一半 + 10% 上线，期间别人能付原价拉走。卖回亚马逊云科技：买价 + 升级 + 容量的实付按 8 折拿回，服务回亚马逊云科技。
  • 全卖了也不够：破产出局，服务按欠款比例分给债主。

专属技能（每个角色一个，一局一次）

  • 总资产低于自己开局资金的一半时，自己回合里发动。
  • 先结算角色自己的技能，再「战略并购」：按卖回价
  • 买下总资产最高的对手的一块服务（钱付给他，不够就欠着）。
  • 在维护窗口里也能发动；用过放一张「技能已用」标记。每个角色的技能写在角色卡上。

每圈运行费（经过 Startup 扶持时交）

按小时EC2、RDS、ECS、EKS…空着也要交
按用量Lambda、DynamoDB…收过路费时交 15%
固定月费S3、EFS、ECR、Route 53、WAF 每圈 $5；KMS 升到客户托管密钥后才收
按 tokenBedrock：过路费 = 点数 × 单价，交 25%
公网 IPv4EC2 每圈 +$5（开私有子网就免）

高可用：AZ 断电打不打得到

绿字自带跨 AZ：Serverless、托管服务、ECS
橙字要自己升多 AZ：EC2、RDS、Aurora、EKS…
红字永远单 AZ：EBS
蓝字全局：Route 53、CloudFront、Shield

扛 Region 故障，不管哪类都要升「多区域」。

怎么赢

  • 经典：别人都破产（最多 50 轮）。
  • 默认 15 轮：按估值排名（现金 + 服务 + 升级×2 + 架构 $200 − 技术债 $100…）。
  • Well-Architected：六大支柱达到本难度要求（入门每条 1 分 / 标准每条 1 分且共 12 分 / 完整每条 2 分 / 地狱每条 2 分且共 18 分）。

奖池和亚马逊云科技

  • 进奖池：两个账单格、Health 罚款、维护窗口 $50、合规审查费。
  • 出奖池：停在 User Group 抽奖拿 $100～全部（不够亚马逊云科技补）；抽到 Free Tier 卡拿走全部。其他花销都付给亚马逊云科技，亚马逊云科技的钱用不完。

技术债

  • 被罚又没抵消就领 1 个：每个让运行费每圈 +$20。2 个：升级每级贵 $50（平时每级 $100 / $150，按用量三格 $50，印在服务卡上）。3 个：停一轮交 $300，或不停交 $400（抽卡攒满的乘卡牌倍率），清空。
  • 重构清 1 个（掷骰子前后随时能做）：$50 × 手上个数，第 10 轮起 +$30。

代理商模式（开关）

  • 代理商不超过一半。开局资金：勾了轮数上限（默认 15 轮）= 角色卡 + 每位客户 $300；不限轮数 = 客户总和；娱乐、地狱只按角色卡。
  • 落在空地上按进货价 5 折占地（地狱 7 折）；自己的地只在组成架构时收过路费，架构 ×2（地狱正常收）。
  • 客户落在代理商的地上可以按转售价买走；架构、整组、升过级的不卖。买走后运行费交给代理商。

维护窗口

  • 走到这格：停一轮，或交 $50 照常走。被送进来：下回合停一轮，或付 $50 / 用 Enterprise Support 出来照常走。
  • 出来时写一句根因，领复盘标记。

六大支柱（每处算 1 分，门槛见正面「怎么赢」）

卓越运营每块 CloudWatch / CloudTrail / Step Functions / EventBridge；写过复盘 +1
安全性每块安全组服务或 CloudFront；演练标记
可靠性每块托管服务；实例多 AZ；多区域 2 分
性能效率每处弹性扩展；每个生效架构
成本优化重构过技术债 / 签过 SP、RI 或用过 Cost Explorer / 每处降成本功能
可持续性每块 Serverless / Graviton / 每处数据分层 / Fargate、Auto Mode

有效架构（凑齐联合收费，节选）

  • Serverless API：API Gateway + Lambda + DynamoDB/Aurora
  • 经典三层 Web：ELB + EC2/ECS + RDS/Aurora 容器平台：ECR + ECS/EKS + ELB 事件驱动：EventBridge + Step Functions + Lambda
  • 订单削峰：EC2/ECS + SQS + Lambda
  • 图片缩略图：S3 + Lambda + CloudFront

全部 48 种见主持人规则书第 23 节；一块服务在几个生效架构里时串联收费，共用的只算一次。

地狱模式

  • 完整局 + 全部玩法 DLC + 高速部署，必须答题，卡牌 ×2。
  • 掷完骰子 1/3 概率随机掉题，不能跳过：答对 +$50，答错 −$50 进奖池。
  • 过路费每 5 轮 +1.5 倍，起点 $150，卖回 6 折，答对只减 30%；每个角色多一条地狱限制。
