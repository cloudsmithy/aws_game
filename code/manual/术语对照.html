二 钱和资产

传统地产类桌游这个游戏有什么不一样
银行亚马逊云科技卖服务、收运行费的那一方，钱付给它就离开了游戏
房子 / 酒店升级（功能） / 容量升级是真实功能：多 AZ、Auto Scaling、多区域……每级有防护效果；容量是节点、并发、分片
抵押下线EC2、RDS、Aurora、Redshift、ECS 能下线：拿回买价一半，不收过路费；至少 3 轮后还一半加原价 10% 才能上线；下线期间别人落上来可以付原价拉走
拍卖（不买就拍卖）不买就是不买落地的人不买，这块留在亚马逊云科技，没有竞价，等下一个落上来的人再决定
卖地给银行卖回亚马逊云科技买价 + 升级 + 容量的实付按 8 折拿回（地狱模式 6 折）
拆房子卖给银行去掉升级 / 减容量退这一级实付的一半
破产账户被暂停全卖了也不够还才破产，服务按欠款比例分给各个债主
免费停车奖池奖池罚款先进奖池，User Group 抽奖或 Free Tier 卡拿走
—运行费传统地产类桌游没有：每圈经过起点时交，按服务计费方式算
—请求费 / token 成本按用量的服务收过路费时交 15%，Bedrock 交 25%
—Spot 购买自己出价买，出了多少只有自己知道（格子上只写 Spot）；别人落上来猜一个价，比你的出价多出原价的 10% 才能抢走，猜低了照常付过路费
—Savings Plans / RI承诺用量换运行费折扣，1 圈算 1 年（完整局）
