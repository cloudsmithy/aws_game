各サービスの役割4 つのサービス

01Kinesisオプション

分析 · マネージド · 時間課金 · 価格 $300
ここでの役割
Kinesis が Web サイトやアプリのクリックストリームをリアルタイムに書き込み、Data Firehose が 1 分単位で保存
使う理由
データが 1 件ずつ絶え間なく届き、リアルタイムで処理したいときに使います：突発的なトラフィックにも耐えられ、複数のコンシューマーが同時に読み取れます
概要
リアルタイムのデータストリーミング：Kinesis Data Streams は毎秒大量のイベントを受け止め、複数のアプリケーションが同時に読み取れます。Data Firehose はデータを S3、Redshift、OpenSearch に直接配信できます。
主な用途
クリックストリームとログのリアルタイム分析、リアルタイムダッシュボード、IoT データ
Kinesis のサービスノート →

02S3必須

ストレージ · サーバーレス · 従量課金 · 価格 $60
ここでの役割
S3 が生データを 1 時間単位のパーティションで保存
使う理由
容量を計画する必要がなく、保存した分だけ支払います。データの耐久性は 99.999999999%（9 が 11 個）です。保存期間が長くなるにつれてアクセスが減るデータは、より安いストレージクラスへ自動で移すこともできます
概要
オブジェクトストレージ：ファイルを「オブジェクト」としてバケットに保存し、保存したデータ量とリクエスト数に応じて課金されます。容量を事前に計画する必要はありません。S3 Standard ストレージクラスは、1 つのリージョン内の 3 つ以上の AZ にデータを保存します。
主な用途
ウェブサイトの画像や静的アセット、データレイク、バックアップとアーカイブ、ログ
S3 のサービスノート →

03Glue必須

分析 · サーバーレス · 従量課金 · 価格 $300
ここでの役割
Glue クローラーがテーブルスキーマを検出してデータカタログを作成
使う理由
データのクレンジング、フォーマットの変換、データカタログの作成のために、自分でクラスターを構築する必要はありません。実行時間に応じて支払います
概要
サーバーレスのデータ統合（ETL）サービス：データソースをクロールしてデータカタログを作成し、Spark ジョブでデータをクレンジング・変換します。実行時間で課金されます。
主な用途
データレイクへのデータ取り込み、Athena や Redshift 向けのデータ準備
Glue のサービスノート →

04Athena必須

分析 · サーバーレス · 従量課金 · 価格 $320
ここでの役割
Athena が SQL で直接クエリし、スキャン量に応じて課金
使う理由
S3 のデータをたまにクエリするときに最も手軽です：データベースの構築もサーバーの管理も不要で、スキャンしたデータ量に応じて支払います
概要
サーバーレスのインタラクティブクエリ：S3 のデータを SQL で直接クエリでき、クラスターの構築は不要です。スキャンしたデータ量で課金されます。データを列指向形式で保存し、日付でパーティション分割すると、スキャン量を大きく減らしてコストを節約できます。
主な用途
ログ分析、データレイクのアドホッククエリ

ゲーム内での計算方法

必須
3 つ：S3、Glue、Athena
オプション
1 つ：Kinesis。なくても完成扱いで、あればまとめて請求
請求方法
そろえると、ほかのプレイヤーがこのアーキテクチャに含まれるあなたのマスのどれに止まっても、アーキテクチャ全体のすべてのサービスの通行料を合計して請求します。「または」のサービスを複数持っていれば、すべて合計に含まれます
金額の目安
アップグレードなし、出目 7 での見積もり：最小構成なら毎回約 $136、すべての部分をそろえると（最適なアーキテクチャ）約 $196。アップグレードすると、さらに大きく増えます
追加ボーナス
Startup クレジットを通過するか止まるたびに、$50 多く受け取れます
