各サービスの役割4 つのサービス

01EBS必須

ストレージ · IaaS · 時間課金 · 価格 $120
ここでの役割
EBS スナップショットでスナップショットロックを有効化（コンプライアンスモードでは期限まで誰も削除できず、root ユーザーでも不可）
使う理由
EBS スナップショットは S3 に保存されます。スナップショットロックを組み合わせれば、ランサムウェアに権限を奪われてもバックアップは削除されません
概要
EC2 用のブロックストレージ（クラウドディスク）：ボリュームを同じ AZ のインスタンスにアタッチしてシステムディスクやデータディスクとして使い、スナップショットでバックアップできます。ボリュームは 1 つの AZ 内にのみ存在します。
主な用途
システムディスク、自前で構築したデータベースのデータディスク
EBS のサービスノート →

02S3必須

ストレージ · サーバーレス · 従量課金 · 価格 $60
ここでの役割
S3 のオブジェクトロックを有効にしたバケットに重要なファイルを保存
使う理由
容量を計画する必要がなく、保存した分だけ支払います。データの耐久性は 99.999999999%（9 が 11 個）です。保存期間が長くなるにつれてアクセスが減るデータは、より安いストレージクラスへ自動で移すこともできます
概要
オブジェクトストレージ：ファイルを「オブジェクト」としてバケットに保存し、保存したデータ量とリクエスト数に応じて課金されます。容量を事前に計画する必要はありません。S3 Standard ストレージクラスは、1 つのリージョン内の 3 つ以上の AZ にデータを保存します。
主な用途
ウェブサイトの画像や静的アセット、データレイク、バックアップとアーカイブ、ログ
S3 のサービスノート →

03GuardDuty必須

セキュリティ · マネージド · 従量課金 · 価格 $380
ここでの役割
GuardDuty マルウェア保護が EBS ボリュームと S3 に新しくアップロードされたファイルをスキャン
使う理由
エージェントをインストールする必要はなく、有効にするだけで CloudTrail、VPC フローログ、DNS ログを分析し、暗号資産のマイニングや認証情報の漏えいといった異常を検出します
概要
脅威検出：CloudTrail イベント、VPC フローログ、DNS ログなどを継続的に分析し、暗号資産のマイニング、認証情報の漏えい、異常なアクセスを検出します。検出のみでブロックはしないため、EventBridge と Lambda を組み合わせて自動で対処します。
主な用途
アカウントのセキュリティ監視、セキュリティイベントへの自動対応
GuardDuty のサービスノート →

04KMSオプション

セキュリティ · マネージド · 従量課金 · 価格 $400
ここでの役割
KMS のカスタマーマネージドキーでスナップショットとオブジェクトを暗号化し、キーの権限は別に管理
使う理由
キーを自分で保管する必要はありません：データを保存するサービスはどれもこれを使って直接暗号化でき、誰がキーを使ったかはすべて CloudTrail に記録されます
概要
マネージドなキー管理：暗号化キーを作成・管理し、S3、EBS、RDS などのサービスがそのキーでデータを暗号化します。キーが平文で KMS の外に出ることはなく、使用のたびに CloudTrail に記録されます。
主な用途
保管中のデータの暗号化、データを復号できるユーザーの制御

ゲーム内での計算方法

必須
3 つ：EBS、S3、GuardDuty
オプション
1 つ：KMS。なくても完成扱いで、あればまとめて請求
請求方法
そろえると、ほかのプレイヤーがこのアーキテクチャに含まれるあなたのマスのどれに止まっても、アーキテクチャ全体のすべてのサービスの通行料を合計して請求します。「または」のサービスを複数持っていれば、すべて合計に含まれます
金額の目安
アップグレードなし、出目 7 での見積もり：最小構成なら毎回約 $112、すべての部分をそろえると（最適なアーキテクチャ）約 $192。アップグレードすると、さらに大きく増えます
追加ボーナス
「ランサムウェアにデータを暗号化された」を無効化（セキュリティ攻防 DLC）：スナップショットもオブジェクトもロックされていて攻撃者は削除できないので、クリーンなスナップショットからそのまま復元できます
