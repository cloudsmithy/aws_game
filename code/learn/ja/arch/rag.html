各サービスの役割5 つのサービス

01S3必須

ストレージ · サーバーレス · 従量課金 · 価格 $60
ここでの役割
S3 に資料を保存
使う理由
容量を計画する必要がなく、保存した分だけ支払います。データの耐久性は 99.999999999%（9 が 11 個）です。保存期間が長くなるにつれてアクセスが減るデータは、より安いストレージクラスへ自動で移すこともできます
概要
オブジェクトストレージ：ファイルを「オブジェクト」としてバケットに保存し、保存したデータ量とリクエスト数に応じて課金されます。容量を事前に計画する必要はありません。S3 Standard ストレージクラスは、1 つのリージョン内の 3 つ以上の AZ にデータを保存します。
主な用途
ウェブサイトの画像や静的アセット、データレイク、バックアップとアーカイブ、ログ
S3 のサービスノート →

02Lambdaオプション

コンピューティング · サーバーレス · 従量課金 · 価格 $220
ここでの役割
Lambda でドキュメントの分割方法とクレンジングをカスタマイズ
使う理由
コード量が少なく、イベントをきっかけに動く処理を任せられます：サーバーやスケーリングを管理する必要がなく、リクエストがなければ料金はかかりません
概要
サーバーレス関数：コードをアップロードすると、イベントが来たときだけ実行されます。リクエスト数と実行時間（ミリ秒単位）で課金され、リクエストがなければ料金はかかりません。1 回の実行は最長 15 分です。
主な用途
API バックエンド、S3 にアップロードされたファイルの処理、定期実行タスク
Lambda のサービスノート →

03OpenSearch必須いずれか 1 つ

分析 · PaaS · 時間課金 · 価格 $360
ここでの役割
Bedrock ナレッジベースがドキュメントをチャンクに分割してベクトルを計算し、OpenSearch または Aurora PostgreSQL（pgvector）に保存
使う理由
全文検索、あいまい検索、ログのリアルタイム検索が必要なときに使います。これらをリレーショナルデータベースで行うと遅いうえ、データベースに負荷がかかります
概要
マネージドな OpenSearch（Elasticsearch から派生したオープンソースプロジェクト）：全文検索、ログ分析、可視化を行い、ベクトルデータベースとしても使えます。
主な用途
サイト内検索、ログ検索、RAG のベクトル検索
OpenSearch のサービスノート →

03Aurora必須いずれか 1 つ

データベース · PaaS · 時間課金 · 価格 $280
ここでの役割
Bedrock ナレッジベースがドキュメントをチャンクに分割してベクトルを計算し、OpenSearch または Aurora PostgreSQL（pgvector）に保存
使う理由
より高いパフォーマンスと可用性を備えた MySQL や PostgreSQL が必要なときに選びます：ストレージは自動で 3 つの AZ にまたがり、リードレプリカの遅延も小さく抑えられます
概要
Amazon Web Services が独自に開発したクラウドネイティブなリレーショナルデータベースで、MySQL および PostgreSQL と互換性があります：データは 3 つの AZ に 6 つのコピーとして保存され、リードレプリカは最大 15 個。Aurora Serverless v2 は負荷に応じて自動でスケールし、Global Database はリージョンをまたいで使えます。
主な用途
高い同時実行性が求められる基幹業務データベース
Aurora のサービスノート →
どれを選ぶか

ベクトルが多く、キーワードとベクトルを組み合わせたハイブリッド検索が必要なら OpenSearch を選びます。すでに PostgreSQL を使っていて、データ量が多くないなら Aurora（pgvector）を選びます

04Bedrock必須

AI · トークン課金 · トークン課金 · 価格 $500
ここでの役割
Bedrock ナレッジベースがドキュメントをチャンクに分割してベクトルを計算し、OpenSearch または Aurora PostgreSQL（pgvector）に保存。Bedrock が関連する部分を検索して回答を生成し、回答には出典が付く
使う理由
すぐに使える基盤モデルをそのまま使いたいときに選びます：1 つの API で複数社のモデルを呼び出せ、GPU の管理は不要で、トークン単位で支払います
概要
複数の企業の基盤モデル（Anthropic Claude、Amazon Nova、Meta Llama、Mistral など）を API で呼び出せ、入力と出力のトークン数で課金されます。ナレッジベース、Agents、Guardrails もあります。お客様のデータがモデルのトレーニングに使われることはありません。
主な用途
チャットボット、コンテンツ生成、AI エージェント
Bedrock のサービスノート →

免責事項：前述の特定の Amazon Web Services の生成 AI 関連サービスは、現在、中国本土以外の Amazon Web Services リージョンで利用できます。Amazon Web Services 中国リージョンのクラウドサービスは西雲数据（NWCD）と光環新網（Sinnet）が運営しています。詳しくは中国リージョンの公式サイトをご確認ください。

ゲーム内での計算方法

必須
3 つ：S3、OpenSearch または Aurora、Bedrock
オプション
1 つ：Lambda。なくても完成扱いで、あればまとめて請求
請求方法
そろえると、ほかのプレイヤーがこのアーキテクチャに含まれるあなたのマスのどれに止まっても、アーキテクチャ全体のすべてのサービスの通行料を合計して請求します。「または」のサービスを複数持っていれば、すべて合計に含まれます
金額の目安
アップグレードなし、出目 7 での見積もり：最小構成なら毎回約 $180、すべての部分をそろえると（最適なアーキテクチャ）約 $296。アップグレードすると、さらに大きく増えます
追加ボーナス
ほかのプレイヤーがあなたの Bedrock に止まると、追加で $50 をあなたに支払います
