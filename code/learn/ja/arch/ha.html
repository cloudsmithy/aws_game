各サービスの役割6 つのサービス

01Route 53必須

ネットワーク · グローバルサービス · 従量課金 · 価格 $160
ここでの役割
Route 53 がヘルスチェック
使う理由
ドメインの名前解決とヘルスチェックをまとめて行えます：片方がダウンしたら、自動でもう片方に切り替わります
概要
マネージド DNS：ドメイン名の登録と名前解決を行い、ヘルスチェックに基づいてフェイルオーバーしたり、レイテンシーや地理的位置に基づいてユーザーを異なるリージョンに誘導したりできます。グローバルサービスで、可用性の SLA は 100% です。
主な用途
ドメイン名の名前解決、リージョン間のディザスタリカバリ切り替え
Route 53 のサービスノート →

02CloudFrontオプション

ネットワーク · グローバルサービス · 従量課金 · 価格 $400
ここでの役割
CloudFront がエッジでリクエストを受け止める
使う理由
ユーザーが広い地域に分散していて、静的コンテンツが多いときに最前面に置きます：ユーザーの近くから返すのでオリジンの負荷が小さく、エッジで攻撃をブロックすることもできます
概要
CDN：ウェブサイト、動画、API を世界中のエッジロケーションにキャッシュし、ユーザーは最寄りの拠点からアクセスするので、オリジンの負荷が軽くなります。Shield Standard が標準で付属し、一般的な DDoS 攻撃を防ぎます。
主な用途
ウェブサイトや静的アセットの高速化、動画配信
CloudFront のサービスノート →

03WAFオプション

セキュリティ · マネージド · 従量課金 · 価格 $400
ここでの役割
WAF が悪意のあるトラフィックをフィルタリング
使う理由
入口でルールに従って、SQL インジェクション、XSS、悪意のあるクローラー、API の不正な大量呼び出しをブロックします。アプリケーションのコードを変更する必要はありません
概要
ウェブアプリケーションファイアウォール：CloudFront、ALB、API Gateway の前に配置し、ルールに従って SQL インジェクション、クロスサイトスクリプティング、悪意のあるボットをブロックします。IP 単位のレート制限もできます。
主な用途
一般的なウェブ攻撃の防御、API の不正な大量呼び出しの防止
WAF のサービスノート →

04ELB必須

ネットワーク · マネージド · 時間課金 · 価格 $140
ここでの役割
ELB が複数の AZ に分散
使う理由
複数のバックエンドの前に統一された入口を置きます：トラフィックを自動で振り分け、故障したインスタンスを避けます。最初から複数の AZ にまたがっています
概要
ロードバランシング：トラフィックを背後の複数の EC2、コンテナ、Lambda に分散し、異常なターゲットを自動的に避けます。ALB は HTTP/HTTPS、NLB は TCP/UDP を処理します。
主な用途
ウェブサイトや API の統一された入口、マルチ AZ の高可用性
ELB のサービスノート →

05EC2必須

コンピューティング · IaaS · 時間課金 · 価格 $100
ここでの役割
EC2 がアプリを実行し、1 台が故障すると ELB は自動でそのインスタンスへの転送をやめる
使う理由
OS を完全に制御したい、特殊なソフトウェアを入れたい、古いアプリケーションを動かしたいときに使います。インスタンスタイプの種類が最も豊富です
概要
クラウド上の仮想サーバー：CPU、メモリ、OS を自分で選び、秒単位で課金されます。オンデマンド、Savings Plans、スポットなどの方法で購入できます。各インスタンスは 1 つの AZ にあるため、高可用性には複数の AZ にそれぞれ数台ずつ配置し、ELB と Auto Scaling を組み合わせます。
主な用途
さまざまなアプリケーションの実行、OS を完全に制御する必要があるケース
EC2 のサービスノート →

06VPCオプション

ネットワーク · マネージド · 無料 · 価格 $140
ここでの役割
VPC を自分で設計して AZ をまたぐパブリックサブネットとプライベートサブネットを用意し、EC2 をプライベートサブネットに配置
使う理由
リソースを自分のプライベートネットワークに置き、サブネットとセキュリティグループで誰がアクセスできるかを決めます。データベースをインターネットに公開する必要はありません
概要
クラウド上のプライベートネットワーク：IP アドレス範囲、サブネット、ルートテーブル、セキュリティグループを自分で設定し、どのリソースがインターネットにアクセスできるかを決めます。VPC 自体は無料です。
主な用途
外部向けのロードバランサーはパブリックサブネットに、アプリケーションとデータベースはプライベートサブネットに配置

ゲーム内での計算方法

必須
3 つ：Route 53、ELB、EC2
オプション
3 つ：CloudFront、WAF、VPC。なくても完成扱いで、あればまとめて請求
請求方法
そろえると、ほかのプレイヤーがこのアーキテクチャに含まれるあなたのマスのどれに止まっても、アーキテクチャ全体のすべてのサービスの通行料を合計して請求します。「または」のサービスを複数持っていれば、すべて合計に含まれます
金額の目安
アップグレードなし、出目 7 での見積もり：最小構成なら毎回約 $80、すべての部分をそろえると（最適なアーキテクチャ）約 $268。アップグレードすると、さらに大きく増えます
追加ボーナス
EC2 の「マルチ AZ Auto Scaling」（マルチ AZ のレベル）へのアップグレードが半額：ELB はもともと複数の AZ にまたがっているので、別の AZ にもう 1 台インスタンスを起動してターゲットグループに登録するだけで済みます

ゲーム内の価格は架空のもので、実際の料金を表すものではありません。$ はゲーム内通貨の単位です。
