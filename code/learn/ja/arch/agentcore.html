各サービスの役割3 つのサービス

01Bedrock必須

AI · トークン課金 · トークン課金 · 価格 $500
ここでの役割
AgentCore Runtime がエージェントをホストして実行し、Bedrock のモデルで推論を繰り返して次の手順を決める
使う理由
すぐに使える基盤モデルをそのまま使いたいときに選びます：1 つの API で複数社のモデルを呼び出せ、GPU の管理は不要で、トークン単位で支払います
概要
複数の企業の基盤モデル（Anthropic Claude、Amazon Nova、Meta Llama、Mistral など）を API で呼び出せ、入力と出力のトークン数で課金されます。ナレッジベース、Agents、Guardrails もあります。お客様のデータがモデルのトレーニングに使われることはありません。
主な用途
チャットボット、コンテンツ生成、AI エージェント
Bedrock のサービスノート →

02AgentCore必須

AI · サーバーレス · 従量課金 · 価格 $100
ここでの役割
AgentCore Runtime がエージェントをホストして実行し、Bedrock のモデルで推論を繰り返して次の手順を決める。AgentCore Gateway が Lambda 関数を MCP ツールとして接続し、業務 API を呼び出す
使う理由
エージェントを本番環境で動かすのに必要な実行環境の分離、セッションのメモリ、ツールゲートウェイ、ID 認証がすべてマネージドで提供されるので、一式を自分で構築する必要はありません
概要
Bedrock AgentCore：AI エージェントを本番環境で運用するためのマネージドプラットフォーム。Runtime がエージェントをホストして実行し（LangGraph、CrewAI、Strands などのフレームワークに対応）、各セッションは専用の microVM で実行され、実際に使ったコンピューティングに応じて課金されます。Memory、Gateway、Identity、Observability などのコンポーネントを必要に応じて組み合わせます。
主な用途
カスタマーサービスのアシスタント、運用アシスタント、業務 API を呼び出せる AI アシスタント
AgentCore のサービスノート →

03Lambda必須

コンピューティング · サーバーレス · 従量課金 · 価格 $220
ここでの役割
AgentCore Gateway が Lambda 関数を MCP ツールとして接続し、業務 API を呼び出す
使う理由
コード量が少なく、イベントをきっかけに動く処理を任せられます：サーバーやスケーリングを管理する必要がなく、リクエストがなければ料金はかかりません
概要
サーバーレス関数：コードをアップロードすると、イベントが来たときだけ実行されます。リクエスト数と実行時間（ミリ秒単位）で課金され、リクエストがなければ料金はかかりません。1 回の実行は最長 15 分です。
主な用途
API バックエンド、S3 にアップロードされたファイルの処理、定期実行タスク
Lambda のサービスノート →

免責事項：前述の特定の Amazon Web Services の生成 AI 関連サービスは、現在、中国本土以外の Amazon Web Services リージョンで利用できます。Amazon Web Services 中国リージョンのクラウドサービスは西雲数据（NWCD）と光環新網（Sinnet）が運営しています。詳しくは中国リージョンの公式サイトをご確認ください。
