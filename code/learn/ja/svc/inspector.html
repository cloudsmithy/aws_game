Inspector

セキュリティ系マネージド従量課金マルチ AZ 標準対応

自動脆弱性スキャン：EC2、ECR のコンテナイメージ、Lambda 関数を継続的にスキャンし、ソフトウェアの脆弱性や意図せず公開されたネットワークポートを見つけ、リスクに応じてスコアを付けます。

主な用途

パッチ管理、コンプライアンスチェック

使う理由

EC2、コンテナイメージ、Lambda の脆弱性を自動で検出します。新しい CVE が公開されても、誰かがスキャンするのを待つ必要はありません

重要ポイント5 件

  1. 自動で継続的な脆弱性管理：EC2、ECR のコンテナイメージ、Lambda 関数を対象に、ソフトウェアの脆弱性（CVE）とネットワークへの露出をスキャンします
  2. 新しい CVE が公開されたり、ソフトウェアパッケージが変わったりすると自動で再評価されるので、定期的に手動でスキャンする必要はありません
  3. リスクスコアは脆弱性の深刻度と実際の露出状況を組み合わせて算出されるので、最も重要なものから修正できます
  4. EC2 のスキャンには SSM Agent を使います。エージェントレススキャン（EBS スナップショットベース）もできます
  5. 検出結果は Security Hub に集約したり、EventBridge に送ったりできます。ソフトウェア部品表（SBOM）もエクスポートできます

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

ゲーム内：あなたの EC2 は重大な CVE を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

ゲーム内：あなたの ECS、EKS、SageMaker AI は重大な CVE を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.3 · レベル 3

Lambda スキャン

Lambda 関数のコードと依存パッケージの脆弱性をスキャンします

ゲーム内：「セキュリティ監査に不合格」を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金
