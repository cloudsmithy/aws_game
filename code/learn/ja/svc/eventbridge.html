EventBridge

アプリケーション統合系サーバーレス従量課金マルチ AZ 標準対応

サーバーレスのイベントバス：Amazon Web Services のサービス、自社のアプリケーション、SaaS から送られるイベントをルールに従って Lambda や Step Functions などに転送し、スケジュールでの起動もできます。

主な用途

イベント駆動型アーキテクチャ、アカウント間のイベント配信、定期実行タスク

使う理由

イベントを送る側と処理する側が互いを知る必要がありません：処理する側を追加しても送信側を変更する必要がなく、スケジュールに従って起動することもできます

重要ポイント5 件

  1. サーバーレスのイベントバス：Amazon Web Services のサービスのイベント、自分のアプリケーションのイベント、SaaS パートナーのイベントをすべて受け取れます
  2. ルールがイベントの内容（イベントパターン）でフィルタリングし、Lambda、SQS、Step Functions などのターゲットに転送します
  3. EventBridge Scheduler：cron 式や一定の間隔でスケジュール実行でき、多くのサービスの API を直接呼び出せるので、Lambda を書く必要はありません
  4. Pipes：SQS、Kinesis、DynamoDB Streams などのソースをターゲットにポイントツーポイントで接続し、途中でフィルタリングや変換ができます
  5. イベントをアーカイブして、後からリプレイできます。Schema Registry はイベントの構造を自動で検出します

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

EC2 の定時起動・停止

EventBridge Scheduler がスケジュールに従ってインスタンスを起動・停止します。開発・テスト環境は夜間と週末に自動で停止し、始業前にまた起動します

ゲーム内：あなたの EC2 の 1 周ごとの運用コストが半額。「テスト環境の削除忘れ」を無効化（FinOps 請求バトル DLC）

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.2 · レベル 2

Health イベント通知

ルールで Health イベントをサブスクライブし、予定されたメンテナンスやインスタンスの廃止の通知が来たらすぐに SNS や Slack に送るので、前もって対応できます

ゲーム内：「EC2 インスタンスのハードウェア廃止」を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.3 · レベル 3

任意の API を呼び出し

Scheduler のユニバーサルターゲットは、スケジュールに従ってほぼすべての Amazon Web Services API を直接呼び出せるので、間に Lambda を書く必要がありません

ゲーム内：運用コストまたはリクエスト料金が半額

運用コスト：通行料を受け取るたびに 8% のリクエスト料金
