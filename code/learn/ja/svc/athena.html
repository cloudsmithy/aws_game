Athena

分析系サーバーレス従量課金マルチ AZ 標準対応

サーバーレスのインタラクティブクエリ：S3 のデータを SQL で直接クエリでき、クラスターの構築は不要です。スキャンしたデータ量で課金されます。データを列指向形式で保存し、日付でパーティション分割すると、スキャン量を大きく減らしてコストを節約できます。

主な用途

ログ分析、データレイクのアドホッククエリ

使う理由

S3 のデータをたまにクエリするときに最も手軽です：データベースの構築もサーバーの管理も不要で、スキャンしたデータ量に応じて支払います

重要ポイント5 件

  1. 標準 SQL で S3 のデータを直接クエリできます。クラスターの構築は不要で、スキャンしたデータ量に応じて課金されます
  2. テーブルのスキーマは Glue データカタログに保存されます。CSV、JSON、Parquet、ORC、Apache Iceberg などの形式に対応しています
  3. コスト削減と高速化：Parquet などの列指向形式に変換し、圧縮し、日付でパーティション分割して、スキャンするデータを減らします
  4. フェデレーテッドクエリを使えば、DynamoDB や RDS などほかのデータソースもあわせてクエリできます
  5. ALB、CloudFront、CloudTrail のログ分析によく使われます

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

パーティション射影

ルールからパーティションの場所を直接計算するので、データカタログを参照する必要がありません。パーティションと組み合わせて必要なデータだけをスキャンするので、スキャン量が少ないほど費用も少なくなります

ゲーム内：運用コストまたはリクエスト料金が半額

運用コスト：通行料を受け取るたびに 8% のリクエスト料金

LV.2 · レベル 2

クエリ結果の再利用

同じクエリには前回の結果をそのまま使います

ゲーム内：このマスの通行料がさらに +20%

運用コスト：通行料を受け取るたびに 8% のリクエスト料金

LV.3 · レベル 3

フェデレーテッドクエリ

1 つの SQL で S3、データベース、ログなど複数のデータソースを同時にクエリします

ゲーム内：通行料アップ

運用コスト：通行料を受け取るたびに 8% のリクエスト料金
