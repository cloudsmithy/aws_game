Cognito

セキュリティ系マネージド従量課金マルチ AZ 標準対応

アプリやウェブサイトのユーザーサインインを管理：ユーザープールはアカウントを保存してサインアップ、サインイン、MFA を担当し、サインイン後に JWT トークンを発行します。ID プールはサインインしたユーザーを一時的な Amazon Web Services 認証情報に交換するので、アプリから S3 などのサービスに直接アクセスできます。月間アクティブユーザー（MAU）で課金されます。

主な用途

アプリやウェブサイトのサインアップとサインイン、API へのサインイン検証の追加（API Gateway と ALB はどちらも Cognito のトークンを直接検証できます）、モバイルアプリから S3 へのファイルの直接アップロード

使う理由

サインインの仕組みを自分で作る必要はありません。パスワードの保存、MFA、パスワードのリセット、ソーシャルサインインがすべて用意されていて、API Gateway や ALB での認証にもそのまま使えます

重要ポイント5 件

  1. ユーザープール：ユーザーディレクトリとサインインの機能です。サインアップ、パスワード、MFA、ソーシャルサインイン、企業向けの SAML や OIDC によるサインインがすべて用意されており、サインイン後に JWT トークンを発行します
  2. ID プール：サインインした ID を一時的な IAM 認証情報に交換し、アプリから S3 や DynamoDB などのサービスを直接呼び出せるようにします
  3. API Gateway は Cognito オーソライザーでトークンを検証できます。ALB はリスナールールで Cognito と直接連携し、サインインを処理できます
  4. マネージドログインページ（Managed Login）で既製のサインイン画面を使え、ブランドに合わせてスタイルを変更できます
  5. 月間アクティブユーザー（MAU）数に応じて課金されます

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

MFA（多要素認証）

サインイン時にパスワードに加えてもう一度確認します（SMS、メールの確認コード、または認証アプリ）。パスワードが漏れても不正にサインインされません

ゲーム内：「ユーザーアカウントがリスト型攻撃を受ける」を無効化（パスワードだけではサインインできない）、「セキュリティ監査に不合格」を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.2 · レベル 2

ソーシャル・企業サインイン

Google や Apple などのソーシャルアカウントや、企業の SAML、OIDC ID プロバイダーと連携します。ユーザーは新しいパスワードを覚えなくてよいので、サインインする人が増えます

ゲーム内：このマスの通行料がさらに +20%

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.3 · レベル 3

ID プール（フェデレーティッドアイデンティティ）

ユーザープールやソーシャルアカウントでサインインした ID を Amazon Web Services の一時的な認証情報に交換します。権限はロールで限定され、アプリは自前のサーバーを経由せずに S3 や DynamoDB などのサービスを直接呼び出せます

ゲーム内：運用コストまたはリクエスト料金が半額

運用コスト：通行料を受け取るたびに 8% のリクエスト料金

1.Cognito のユーザープールと ID プールの違いは何ですか？
正解ユーザープールはサインアップとサインインを管理してトークンを発行し、ID プールはサインインしたユーザーを Amazon Web Services の一時的な認証情報に交換する
ユーザープールはユーザーディレクトリで、サインアップ、サインイン、MFA を担当し、サインイン後に JWT を発行します。ID プールは、ユーザープールやソーシャルアカウントでサインインした ID を一時的な認証情報に交換し、S3 などのサービスに直接アクセスできるようにします
2.API Gateway でサインイン済みのユーザーだけを通すには、どの方法が最も手軽ですか？
正解API に Cognito ユーザープールのオーソライザーを設定し、サインイン時に取得したトークンをリクエストに付ける
API Gateway の Cognito オーソライザー（HTTP API では JWT オーソライザー）が先にトークンを検証するため、未サインインやトークン期限切れのリクエストはゲートウェイで拒否され、Lambda に検証ロジックを書く必要はありません
3.他所で漏えいしたパスワードを使って、あなたのアプリにリスト型攻撃を仕掛けてくる者がいます。Cognito のどの機能が最も適していますか？
正解脅威保護：漏えいしたパスワードの使用や異常なサインインを検出し、リスクに応じてブロックするか、追加の MFA を求める
脅威保護（以前の名称は高度なセキュリティ機能で、Plus 機能プランに含まれる）は漏えいした認証情報をチェックし、異常なサインインをリスクレベルに応じて自動でブロックするか、再度の検証を求めます
