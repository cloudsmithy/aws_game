Route 53

ネットワーク系グローバルサービス従量課金グローバルサービス

マネージド DNS：ドメイン名の登録と名前解決を行い、ヘルスチェックに基づいてフェイルオーバーしたり、レイテンシーや地理的位置に基づいてユーザーを異なるリージョンに誘導したりできます。グローバルサービスで、可用性の SLA は 100% です。

主な用途

ドメイン名の名前解決、リージョン間のディザスタリカバリ切り替え

使う理由

ドメインの名前解決とヘルスチェックをまとめて行えます：片方がダウンしたら、自動でもう片方に切り替わります

重要ポイント5 件

  1. マネージド DNS とドメイン登録を提供し、サービスレベルアグリーメント（SLA）で 100% の可用性を約束しています
  2. ルーティングポリシー：シンプル、加重、レイテンシー、フェイルオーバー、位置情報、地理的近接性、複数値回答
  3. ヘルスチェックとフェイルオーバールーティングの組み合わせ：プライマリサイトがダウンすると、ユーザーを自動でセカンダリサイトに切り替えます
  4. エイリアスレコード（Alias）は ELB、CloudFront、S3 の静的ウェブサイトなどを直接指すことができ、こうしたクエリは無料です
  5. プライベートホストゾーンは、関連付けた VPC 内でのみ名前解決できます
