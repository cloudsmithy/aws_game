Bedrock

AI グループトークン課金トークン課金マルチ AZ 標準対応

複数の企業の基盤モデル（Anthropic Claude、Amazon Nova、Meta Llama、Mistral など）を API で呼び出せ、入力と出力のトークン数で課金されます。ナレッジベース、Agents、Guardrails もあります。お客様のデータがモデルのトレーニングに使われることはありません。

免責事項：前述の特定の Amazon Web Services の生成 AI 関連サービスは、現在、中国本土以外の Amazon Web Services リージョンで利用できます。Amazon Web Services 中国リージョンのクラウドサービスは西雲数据（NWCD）と光環新網（Sinnet）が運営しています。詳しくは中国リージョンの公式サイトをご確認ください。

主な用途

チャットボット、コンテンツ生成、AI エージェント

使う理由

既存の大規模モデルをそのまま使いたいときに選びます：1 つの API で複数社のモデルを呼び出せ、GPU の管理は不要で、トークン単位で支払います

重要ポイント5 件

  1. フルマネージドの生成 AI サービス：1 つの API で、複数の企業の基盤モデル（Anthropic Claude、Amazon Nova、Meta Llama、Mistral など）を呼び出せます
  2. 入力トークンと出力トークンの数に応じて課金されます。使用量が多い場合は、プロビジョンドスループットを購入できます
  3. Knowledge Bases で RAG を構築：S3 のデータをチャンクに分割してベクトル化し、ベクトルストア（OpenSearch Serverless、Aurora PostgreSQL など）に保存します
  4. Guardrails で有害なコンテンツや機密情報をフィルタリングします。Agents はツールを呼び出して、複数ステップのタスクを実行できます
  5. あなたのプロンプトやデータが基盤モデルのトレーニングに使われることはありません

比較と選び方

Bedrock と SageMaker AI

既存の大規模モデル（Claude、Nova、Llama など）をそのまま使うなら Bedrock を選び、トークン単位で支払います。自分でモデルをトレーニング・ファインチューニングしたい、またはオープンソースのモデルをデプロイしたいなら SageMaker AI を選びます

1.Amazon Bedrock は何のためのサービスですか？
正解複数の企業の基盤モデルを API で呼び出せるマネージドサービス
入力と出力のトークン数で課金されます。時間課金のプロビジョンドスループットを購入することもできます
2.Bedrock Knowledge Bases の主な用途は何ですか？
正解検索拡張生成（RAG）
自分のデータをモデルにつなぎ、検索拡張を行います
3.Bedrock のクロスリージョン推論は何をするものですか？
正解リクエストを複数のリージョンに分散して処理し、突発的なトラフィックに耐える
地理的クロスリージョン推論は米国や EU などの範囲内でのみ振り分け、グローバルクロスリージョン推論は世界中に振り分けて約 10% 安くなります。このリージョン自体に問題が起きると、やはり呼び出せません
4.Bedrock Guardrails は何に使いますか？
正解有害なコンテンツをフィルタリングし、機密情報をマスクする
さまざまなモデルの前段に置いて共通で使えます
5.Bedrock Knowledge Bases では、ユーザーがアップロードしたデータはどこに保存されて検索されますか？
正解OpenSearch Serverless などのベクトルデータベース
データをチャンクに分割してベクトルに変換・保存し、質問時はまず検索してから生成します
6.数十万件の商品説明をモデルで書き換える必要があります。結果は数日以内に出れば問題ありません。Bedrock で最も適した方法はどれですか？
正解バッチ推論：ジョブを送信し、結果は S3 に書き込まれる
オンデマンドより 50% 安くなりますが、完了時間は保証されません。ジョブはデフォルトで 24 時間でタイムアウトし、最大 168 時間まで設定できます
7.呼び出しのたびに、同じ長いシステムプロンプトと参考ドキュメントを送っています。入力料金を節約し、レイテンシーも下げられる Bedrock の機能はどれですか？
正解プロンプトキャッシュ（Prompt caching）
繰り返し使う長いコンテキストをキャッシュするので、後続のリクエストで再処理する必要がありません。対応モデルはドキュメントで確認してください
8.より小さく安価なモデルで、自社の業務シナリオにおいて大規模モデルに近い結果を得たい場合、Bedrock の何を使いますか？
正解モデル蒸留：大規模モデルが教師となって小さなモデルを教える
大規模モデルが合成データを生成し、それで小さなモデルをファインチューニングします。その後は小さなモデルを呼び出すので、速くて安価です
