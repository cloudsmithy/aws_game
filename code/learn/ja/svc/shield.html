Shield Advanced

セキュリティ系グローバルサービスサブスクリプショングローバルサービス

DDoS 防御：すべてのアカウントに Shield Standard が無料で付属し、一般的なネットワーク層の攻撃を防ぎます。Shield Advanced は有料のサブスクリプションで、アプリケーション層の保護、DDoS レスポンスチームのサポート、攻撃中のスケーリング費用の補償が加わります。

主な用途

DDoS の影響を受けやすい大規模ウェブサイト、ゲーム、金融業務

使う理由

大規模な DDoS に耐えます：専門チームが 24 時間 365 日対応し、攻撃中に増えたスケールアウト費用についてはクレジットを申請できます

重要ポイント5 件

  1. Shield Standard：すべてのお客様が自動的に無料で利用でき、一般的なネットワーク層とトランスポート層の DDoS を防ぎます
  2. Shield Advanced：有料（月額固定料金とデータ転送料金）で、CloudFront、Route 53、ELB、EC2 の Elastic IP、Global Accelerator を保護します
  3. Advanced には 24 時間 365 日対応の Shield Response Team（SRT）があり、攻撃中に増えたスケーリング費用についてはクレジットを申請でき、攻撃の状況もより詳しく確認できます
  4. WAF と組み合わせると、アプリケーション層（レイヤー 7）の DDoS を自動で緩和できます
  5. 外部向けで、トラフィックの多い重要な業務に向いています

4.ある小さな会社のウェブサイトは Amazon Web Services 上にデプロイされており、追加の保護サービスは一切購入していません。一般的なネットワーク層およびトランスポート層の DDoS 攻撃に対して、自動的に受けられる保護はどれですか？CLF-C02
正解Shield Standard、追加料金なし
すべての顧客は追加料金なしで自動的に Shield Standard によって保護され、最も一般的なネットワーク層およびトランスポート層の DDoS 攻撃から防御されます。Shield Advanced は別途有料のサブスクリプションが必要です。Macie と Artifact は DDoS 対策とは関係ありません。　公式ドキュメント ↗
5.あるゲーム会社は過去に大規模な DDoS 攻撃を受けたことがあり、攻撃中に Amazon Web Services の専門家チームの支援を受けるとともに、攻撃によって生じる一部の料金の急増から保護されたいと考えています。どのサービスを選ぶべきですか？SAA-C03
正解Shield Advanced をサブスクライブする
Shield Advanced は、Shield Response Team（SRT）によるサポートと、DDoS による料金の急増に対するコスト保護を提供します。Shield Standard は無料で自動的に適用されますが、この 2 つは含まれません。GuardDuty は脅威検出、Inspector は脆弱性スキャンに使うもので、いずれも DDoS 対策のサービスではありません。　公式ドキュメント ↗
