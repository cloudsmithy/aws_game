Config

モニタリング系従量課金従量課金ワイルドカードサービス

設定の記録とコンプライアンスチェック：アカウント内の各リソースの設定と変更履歴を継続的に記録し、ルールで準拠しているかをチェックします（たとえば S3 バケットが公開されていないか、EBS ボリュームが暗号化されているか）。準拠していないリソースは自動で修復できます。

主な用途

コンプライアンス監査、誰が設定を壊したかの調査、公開された S3 バケットを自動でプライベートに戻す

使う理由

リソースの設定がどう変わったかを記録し、コンプライアンスに準拠しているかを自動でチェックします

重要ポイント5 件

  1. リソースの設定と変更履歴を記録します：あるセキュリティグループが、いつ、誰によって、どう変更されたか
  2. Config ルール（マネージドルールまたは自作のルール）で、リソースが準拠しているかを継続的にチェックします。たとえば「S3 バケットは公開しない」「EBS ボリュームは必ず暗号化する」など
  3. 準拠していないリソースは自動で修復できます（Systems Manager Automation ドキュメントを呼び出す）
  4. コンフォーマンスパックで一連のルールをまとめてデプロイします。アグリゲーターで、複数のアカウント・リージョンのコンプライアンス状況を集約します
  5. 記録された設定項目の数と、ルールの評価回数に応じて課金されます

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

マネージドルール

マネージドルールで、リソースの設定がコンプライアンスに準拠しているかを継続的にチェックします。たとえば S3 バケットが公開されていないか、EBS ボリュームが暗号化されているかなどです

ゲーム内：「セキュリティ監査に不合格」を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.2 · レベル 2

自動修復

準拠していないリソースを Systems Manager Automation ドキュメントで自動的に元に戻します。たとえば公開された S3 バケットを非公開に戻します

ゲーム内：「誰かが本番環境の設定を手作業で変更」を無効化、「S3 バケットがパブリックに設定された」を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.3 · レベル 3

アグリゲーター

複数のアカウントとリージョンの設定とコンプライアンスの結果を 1 か所に集約して確認できます

ゲーム内：通行料アップ

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

使われるアーキテクチャ3 個

S3 パブリックアクセスの自動ブロック必須

Config のマネージドルール（s3-bucket-public-read-prohibited など）がすぐに検出し、自動修復で Systems Manager Automation ドキュメントを実行して、このバケットの「パブリックアクセスのブロック」を有効化

解説動画図解ガイド

セキュリティグループの自動制限必須

Config ルール restricted-ssh が検出し、自動修復で Systems Manager Automation ドキュメント AWS-DisablePublicAccessForSecurityGroup を実行してこのルールを削除

解説動画図解ガイド

セキュリティベースライン必須

Config が設定のコンプライアンスをチェックし、非準拠の設定を自動で元に戻す
