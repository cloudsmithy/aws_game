SERVICEAI 系 · PaaS

SageMaker AI

AI 系PaaS時間課金マルチ AZ は自前で構成

機械学習プラットフォーム：データの準備、トレーニング、チューニング、モデルのデプロイを行えます。マネージドなノートブック環境があり、推論エンドポイントはインスタンスの稼働時間で課金されます。

主な用途

独自モデルのトレーニング、推論サービスのデプロイ

使う理由

モデルを自分でトレーニング、ファインチューニング、デプロイしたいときに使います：トレーニング、チューニング、本番リリース、モニタリングを 1 つのプラットフォームで行えます

重要ポイント5 件

  1. Amazon SageMaker AI：機械学習モデルの構築、トレーニング、デプロイを行うフルマネージドのプラットフォームです
  2. トレーニング：マネージドなトレーニングジョブ。スポットトレーニングでコストを抑えられ、分散トレーニングにも対応しています
  3. デプロイ：リアルタイム推論エンドポイント、サーバーレス推論、非同期推論、バッチ変換
  4. JumpStart は事前トレーニング済みモデルとすぐに使えるソリューションを提供し、オープンソースの大規模モデルをワンクリックでデプロイできます
  5. トレーニングデータは通常 S3 に置き、独自のトレーニング用・推論用のイメージは ECR に置きます

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

マルチ AZ 推論エンドポイント

推論インスタンスを複数の AZ に分散します

ゲーム内：AZ の停電と単一障害点に耐える

運用コスト：1 周ごとに $20

LV.2 · レベル 2

マルチ GPU トレーニング（GPU クラスター）

まずトレーニングプランで GPU をまとめて予約し、複数の GPU で並列にトレーニングします。より大きなモデルを、より速くトレーニングできます

ゲーム内：「GPU キャパシティ不足」を無効化（GenAI ウェーブ DLC）、このマスの通行料がさらに +20%

運用コスト：1 周ごとに $30

LV.3 · レベル 3

独自の大規模モデルをトレーニング（HyperPod）

HyperPod クラスターで独自の基盤モデルをトレーニングし、故障したノードは自動で交換されます

ゲーム内：通行料アップ

運用コスト：1 周ごとに $40

比較と選び方

Bedrock か SageMaker AI

すぐに使える基盤モデル（Claude、Nova、Llama など）をそのまま使うなら Bedrock を選び、トークン単位で支払います。自分でモデルをトレーニング・ファインチューニングしたい、またはオープンソースのモデルをデプロイしたいなら SageMaker AI を選びます

1.SageMaker AI でモデルをリアルタイム推論サービスとしてデプロイしたものを何と呼びますか？
正解エンドポイント（Endpoint）
非同期推論やバッチ変換にも対応しています
2.デフォルト設定の場合、SageMaker AI のリアルタイム推論エンドポイントは、トラフィックがないときも課金されますか？
正解はい、インスタンスが起動したままになる
インスタンス時間で課金されます。トラフィックが少ない場合は Serverless や非同期推論を使えます。推論コンポーネントをホストするエンドポイントなら、インスタンス数を 0 まで縮小することもできます
3.SageMaker HyperPod の主な用途は何ですか？
正解大規模な分散トレーニング。ノードが故障すると自動で交換される
基盤モデルのトレーニングは数週間かかることも多く、ノード障害からの自動復旧が重要です
4.あるデータサイエンティストは Amazon SageMaker Studio で作業しており、さまざまなモデルハブの事前トレーニング済みモデルを閲覧し、選択したモデルをそのままファインチューニング、デプロイ、評価したいと考えています。どの機能を使用すべきですか？AIF-C01
正解Amazon SageMaker JumpStart
JumpStart は多数の事前トレーニング済みモデル、ソリューションテンプレート、サンプルノートブックを提供しており、Studio の Models ページでモデルのファインチューニング、デプロイ、評価を行えます。Model Monitor は本番環境のモニタリング、Clarify はバイアスと説明可能性、Ground Truth はデータのラベル付けに使用します。　公式ドキュメント ↗
5.ある企業は、トレーニング済みのモデルを使って毎晩大規模なデータセット全体をスコアリングする必要があり、日中はオンライン予測を一切必要としません。Amazon SageMaker AI を使用する場合、最も適切な推論方法はどれですか？AIF-C01
正解バッチ変換（batch transform）。常時稼働の推論エンドポイントは不要
公式ドキュメントによると、バッチ変換は大規模なデータセットに対して推論を行い、永続的なエンドポイントを必要としない場合に適しています。リアルタイム推論は、低レイテンシーでインタラクティブな応答が必要なワークロード向けです。　公式ドキュメント ↗
6.ある金融企業はローン審査モデルを開発しており、トレーニングデータで特定のグループのサンプル数が著しく少なくないかを確認するとともに、個々の予測に対する各特徴量の寄与を説明する必要があります。この 2 つの機能を専門に提供する Amazon Web Services のツールはどれですか？AIF-C01
正解Amazon SageMaker Clarify
Clarify は、トレーニング前のバイアス指標（クラスの不均衡 CI など）を計算し、Shapley 値に基づく特徴量アトリビューションで予測を説明できます。注意：公式ドキュメントによると、Clarify は新規のお客様への提供を終了していますが、既存のお客様は引き続き利用できます。　公式ドキュメント ↗
7.すでに本番稼働している信用スコアリングモデルについて、チームは本番データの変化に伴ってモデルの予測に徐々にバイアスドリフトが生じ、精度も低下することを懸念しており、逸脱が生じたら自動でアラートを出したいと考えています。どの機能を使用すべきですか？AIF-C01
正解Amazon SageMaker Model Monitor
Model Monitor は、本番モデルのデータ品質、モデル品質、バイアスドリフト、特徴量アトリビューションドリフトを継続的にモニタリングし、逸脱が生じるとアラートを出します。注意：公式ドキュメントによると、Model Monitor は新規のお客様への提供を終了していますが、既存のお客様は引き続き利用できます。　公式ドキュメント ↗
