GuardDuty

セキュリティ系マネージド従量課金マルチ AZ 標準対応

脅威検出：CloudTrail イベント、VPC フローログ、DNS ログなどを継続的に分析し、暗号資産のマイニング、認証情報の漏えい、異常なアクセスを検出します。検出のみでブロックはしないため、EventBridge と Lambda を組み合わせて自動で対処します。

主な用途

アカウントのセキュリティ監視、セキュリティイベントへの自動対応

使う理由

エージェントをインストールする必要はなく、有効にするだけで CloudTrail、VPC フローログ、DNS ログを分析し、暗号資産のマイニングや認証情報の漏えいといった異常を検出します

重要ポイント5 件

  1. 脅威検出：CloudTrail の管理イベント、VPC フローログ、DNS ログを分析します。エージェントのインストールは不要です
  2. 追加で有効にできる保護：S3、EKS 監査ログ、ランタイムモニタリング、マルウェアスキャン、RDS ログインアクティビティ、Lambda ネットワークアクティビティ
  3. 検出結果（finding）は重要度で分類され、EventBridge に送って自動で対処できます
  4. 複数のアカウントは、委任管理者アカウントで一元管理します
  5. 機械学習と脅威インテリジェンスで、暗号資産のマイニング、認証情報の漏えい、異常な API 呼び出しなどの行為を検出します
