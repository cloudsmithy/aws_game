AgentCore

AI 系サーバーレス従量課金マルチ AZ 標準対応

Bedrock AgentCore：AI エージェントを本番環境で運用するためのマネージドプラットフォーム。Runtime がエージェントをホストして実行し（LangGraph、CrewAI、Strands などのフレームワークに対応）、各セッションは専用の microVM で実行され、実際に使ったコンピューティングに応じて課金されます。Memory、Gateway、Identity、Observability などのコンポーネントを必要に応じて組み合わせます。

免責事項：前述の特定の Amazon Web Services の生成 AI 関連サービスは、現在、中国本土以外の Amazon Web Services リージョンで利用できます。Amazon Web Services 中国リージョンのクラウドサービスは西雲数据（NWCD）と光環新網（Sinnet）が運営しています。詳しくは中国リージョンの公式サイトをご確認ください。

主な用途

カスタマーサービスのアシスタント、運用アシスタント、業務 API を呼び出せる AI アシスタント

使う理由

エージェントを本番環境で動かすのに必要な実行環境の分離、セッションのメモリ、ツールゲートウェイ、ID 認証がすべてマネージドで提供されるので、一式を自分で構築する必要はありません

重要ポイント4 件

  1. Amazon Bedrock AgentCore：エージェントを本番環境にデプロイして運用するためのマネージドサービスです。フレームワーク（Strands Agents、LangGraph、CrewAI など）もモデルも問いません
  2. Runtime：エージェントをサーバーレスで実行します。セッションごとに分離され、長時間実行されるタスクにも対応します
  3. Memory は短期メモリと長期メモリを管理します。Gateway は既存の API や Lambda 関数を、エージェントが呼び出せる MCP ツールに変換します。Identity は、エージェントがほかのサービスにアクセスするときの ID と認証情報を管理します
  4. ほかにも Code Interpreter（サンドボックスでコードを実行）、Browser（マネージドブラウザ）、Observability（トレースとモニタリング）があります

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

Memory（記憶）

短期メモリには現在のセッションのコンテキストを保存し、長期メモリにはセッションをまたいでユーザーの好みや重要な事実を記憶します

ゲーム内：通行料アップ

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.2 · レベル 2

Gateway（ツールゲートウェイ）

既存の API や Lambda 関数を MCP ツールとして接続し、エージェントが業務 API を直接呼び出せるようにします

ゲーム内：このマスの通行料がさらに +20%

運用コスト：通行料を受け取るたびに 15% のリクエスト料金

LV.3 · レベル 3

Identity（ID 管理）

エージェントが独自の ID を持ちます。ユーザーの代わりにサードパーティのサービスを呼び出すときは OAuth で認可するので、シークレットをコードに書かずに済みます

ゲーム内：「セキュリティ監査に不合格」を無効化

運用コスト：通行料を受け取るたびに 15% のリクエスト料金
