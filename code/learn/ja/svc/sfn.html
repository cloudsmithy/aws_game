Step Functions

アプリケーション統合グループServerless従量課金マルチ AZ 標準対応

視覚的なワークフローのオーケストレーション：Lambda、コンテナタスク、各種サービスの API 呼び出しをステートマシンとしてつなぎ、再試行、分岐、並列処理を標準で備えます。人による承認を待つこともできます。

主な用途

注文処理フロー、データ処理パイプライン、AI エージェントのステップのオーケストレーション

使う理由

複数ステップのワークフローのために、ステートマシンを自分で書く必要はありません：各ステップの再試行、タイムアウト、失敗時のロールバックを設定でき、どのステップまで実行したかも確認できます

重要ポイント5 件

  1. ビジュアルなワークフローのオーケストレーション：ステートマシンでステップ、分岐、並列処理、待機を記述します
  2. ワークフローは 2 種類：標準（最長 1 年、1 回だけの実行を保証、長いプロセス向け）と Express（最長 5 分、高スループット、実行回数と実行時間に応じて課金）
  3. 各ステップに再試行、タイムアウト、エラーのキャッチを設定でき、エラー時は補償処理に移れます
  4. 多くのサービスの API を直接呼び出せる（SDK 統合）ので、すべてを Lambda 経由にする必要はありません
  5. 実行履歴が可視化され、各ステップの入力と出力を確認できるので、トラブルシューティングが簡単です

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

Express ワークフロー

5 分以内に終わる高頻度の短いワークフローに向いています。状態遷移の数ではなく、実行回数と実行時間（メモリ量で換算）で課金されるので、ステップが多く短時間で終わる処理ほど安くなります

ゲーム内：運用コストまたはリクエスト料金が半額

運用コスト：通行料を受け取るたびに 8% のリクエスト料金

LV.2 · レベル 2

分散マップ

数百万の項目を並列処理します

ゲーム内：このマスの通行料がさらに +20%

運用コスト：通行料を受け取るたびに 8% のリクエスト料金

LV.3 · レベル 3

マルチリージョン

複数のリージョンにステートマシンをデプロイします（実際にはワンクリックの切り替え機能はなく、別のリージョンにもう 1 セットを自分でデプロイし、Route 53 やアプリケーション側で切り替えます）

ゲーム内：リージョン全体の障害に耐える

運用コスト：通行料を受け取るたびに 8% のリクエスト料金
