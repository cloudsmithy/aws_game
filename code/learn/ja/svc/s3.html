S3

ストレージ系サーバーレス従量課金マルチ AZ 標準対応

オブジェクトストレージ：ファイルを「オブジェクト」としてバケットに保存し、保存したデータ量とリクエスト数に応じて課金されます。容量を事前に計画する必要はありません。S3 Standard ストレージクラスは、1 つのリージョン内の 3 つ以上の AZ にデータを保存します。

主な用途

ウェブサイトの画像や静的アセット、データレイク、バックアップとアーカイブ、ログ

使う理由

容量を計画する必要がなく、保存した分だけ支払います。データの耐久性は 99.999999999%（9 が 11 個）です。保存期間が長くなるにつれてアクセスが減るデータは、より安いストレージクラスへ自動で移すこともできます

重要ポイント6 件

  1. オブジェクトストレージ：データは「バケット + キー」で保存・取得します。ファイルシステムでも、マシンにアタッチするディスクでもありません
  2. ストレージクラスはホットからコールドの順に S3 Standard、Intelligent-Tiering、Standard-IA、One Zone-IA、Glacier Instant Retrieval、Glacier Flexible Retrieval、Glacier Deep Archive です。コールドなクラスほど安くなりますが、取り出しが遅くなるか、別途取り出し料金がかかります
  3. 2020 年 12 月以降、読み書きはすべて強い整合性を持ちます：書き込んだ直後に読み取っても、新しいデータが返ります
  4. 新しく作成したバケットでは、デフォルトでパブリックアクセスのブロックが有効、ACL が無効になっていて、新しいオブジェクトはデフォルトで SSE-S3 で暗号化されます
  5. バージョニング、ライフサイクルルール、オブジェクトロック（WORM：書き込みは 1 回、読み取りは何度でも）を組み合わせて、誤削除やランサムウェアを防ぎます
  6. イベント通知で Lambda を直接起動したり、SQS、SNS、EventBridge に送ったりできます

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

LV.1 · レベル 1

バージョニング

各オブジェクトの過去のバージョンを保持し、誤って削除・変更しても元に戻せます

ゲーム内：データの誤削除を無効化

運用コスト：1 周ごとに $5、通行料を受け取るたびに 15% のリクエスト料金

LV.2 · レベル 2

Intelligent-Tiering

アクセス頻度に応じて、データを安いストレージ階層へ自動で移動します

ゲーム内：運用コストまたはリクエスト料金が半額

運用コスト：1 周ごとに $5、通行料を受け取るたびに 8% のリクエスト料金

LV.3 · レベル 3

サムネイルの自動生成

画像がアップロードされるとすぐに S3 イベント通知が Lambda を起動してサムネイルを生成し、別のバケットまたはプレフィックスに書き戻します

ゲーム内：このマスの通行料がさらに +20%

運用コスト：1 周ごとに $5、通行料を受け取るたびに 8% のリクエスト料金

比較と選び方

EFS か S3

トレーニングデータが大量で、ファイル単位でまとめて読むなら S3 に置きます（安価です）。複数のマシンでローカルディスクのように共有して読み書きしたいなら EFS を使います

OpenSearch か Redshift か S3

安く長期保存してオフラインで分析するなら S3 のデータレイクに置きます。秒単位で結果が返る SQL レポートが必要なら Redshift に、リアルタイムの検索が必要なら OpenSearch に入れます

正解 0 / 8、回答済み 0

1.プライベートサブネットのインスタンスから S3 にアクセスするとき、NAT ゲートウェイを経由せず、データ処理料金も払わずに済ませるにはどうしますか？
正解S3 のゲートウェイエンドポイントを作成する
S3 と DynamoDB のゲートウェイエンドポイントは無料です
2.S3 にある、めったにアクセスしないが何年も保管する必要があるアーカイブデータは、どのストレージクラスに置くのが最も安いですか？
正解S3 Glacier Deep Archive
標準取り出しは 12 時間以内、一括取り出しは 48 時間以内で、Flexible Retrieval よりかなり遅くなります。最小ストレージ期間は 180 日です
3.S3 や EFS のようなサービスでは、マルチ AZ を自前で構成する必要がありますか？
正解いいえ、デフォルトで複数の AZ にデータが保存される
S3 標準ストレージクラスは少なくとも 3 つの AZ にデータを保存します。S3 One Zone-IA や EFS One Zone のような単一 AZ のクラスは例外です
4.S3 標準ストレージの設計上の耐久性はどれですか？
正解99.999999999%（9 が 11 個）
耐久性は 9 が 11 個です。可用性はまた別の話です
5.S3 オブジェクト 1 つの最大サイズはどれですか？
正解50 TB
2025 年 12 月に 5 TB から 50 TB に引き上げられました。1 回の PUT は最大 5 GB で、それより大きい場合はマルチパートアップロードを使います
6.2023 年 4 月以降、新しく作成した S3 バケットのデフォルトの状態はどれですか？
正解パブリックアクセスのブロックが有効、ACL は無効
公開したい場合は、自分でパブリックアクセスのブロックを明示的にオフにする必要があります
7.S3 Intelligent-Tiering の特徴はどれですか？
正解アクセス頻度に応じてストレージ階層を自動で移動し、取り出し料金がかからない
アクセスパターンが予測できないデータに向いています。オブジェクトごとに少額のモニタリング料金がかかります
8.Athena で S3 上のデータをクエリするとき、最もコストを抑えられる方法はどれですか？
正解Parquet などの列指向形式を使い、パーティション分割する
Athena はスキャンしたデータ量で課金されるため、スキャンが少ないほど安くなります
