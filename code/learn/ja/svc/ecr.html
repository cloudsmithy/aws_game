ECR

コンテナ系マネージド従量課金マルチ AZ 標準対応

マネージドなコンテナイメージレジストリ：Docker / OCI イメージを保存し、脆弱性をスキャンできます。ECS と EKS はここから直接イメージをプルします。

主な用途

CI/CD でビルドしたイメージをプッシュし、デプロイ時にプル

使う理由

イメージをデプロイ先のすぐそばに置けます：ECS や EKS と権限が連携していて、プッシュ時には脆弱性もあわせてスキャンします

重要ポイント5 件

  1. マネージドなコンテナイメージレジストリで、Docker イメージや OCI アーティファクト（Helm チャートなど）を保存します
  2. 誰がプッシュ・プルできるかを IAM で制御します。ECS、EKS、Lambda（コンテナイメージでのデプロイ）はここから直接プルします
  3. イメージスキャン：基本スキャンのほか、Inspector に任せる拡張スキャンも使えます。拡張スキャンでは、新しい CVE が公開されると継続的に再スキャンします
  4. ライフサイクルポリシーで古いイメージを自動で削除できます。リージョン間・アカウント間のレプリケーションもできます
  5. タグをイミュータブル（変更不可）に設定すると、同じタグが新しいイメージで上書きされなくなります

3 つの主な機能ゲームの 3 段階のアップグレードは、実際のサービスにあるこの 3 つの機能です

運用コスト：1 周ごとに $5、通行料を受け取るたびに 15% のリクエスト料金

運用コスト：1 周ごとに $5、通行料を受け取るたびに 15% のリクエスト料金
