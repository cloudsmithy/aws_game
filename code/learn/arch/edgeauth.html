每一块干什么4 块服务

01Cognito必须

安全组 · 托管服务 · 按用量 · 售价 $80
在这里
用户先在 Cognito 登录拿到令牌
为什么用它
登录这件事不用自己写：密码存储、MFA、找回密码、社交登录都是现成的，还能直接给 API Gateway 和 ALB 做鉴权
它是什么
给你的 App 和网站管用户登录：用户池存账号，负责注册、登录、MFA，登录后发 JWT 令牌；身份池把登录的用户换成临时的亚马逊云科技凭证，App 可以直接访问 S3 这类服务。按月活跃用户（MAU）计费。
常见用法
App 和网站的注册登录、给 API 加登录校验（API Gateway、ALB 都能直接认 Cognito 的令牌）、手机 App 直传文件到 S3

02CloudFront必须

网络组 · 全局服务 · 按用量 · 售价 $400
在这里
每个请求到了 CloudFront 边缘节点
为什么用它
用户分布广、静态内容多时放在最前面：就近返回，源站压力小，还能在边缘挡攻击
它是什么
CDN：把网站、视频和 API 缓存到全球各地的边缘站点，用户就近访问，减轻源站压力；自带 Shield Standard 挡常见的 DDoS。
常见用法
网站和静态资源加速、视频分发
CloudFront 的知识点 →

03Lambda必须

计算组 · Serverless · 按用量 · 售价 $220
在这里
Lambda@Edge 先验令牌
为什么用它
代码不多、按事件触发的活交给它：不用管服务器和扩容，没请求就不花钱
它是什么
无服务器函数：上传代码，有事件来才运行，按请求次数和运行时长（毫秒）收费，没请求不收钱；单次最长运行 15 分钟。
常见用法
API 后端、处理 S3 上传的文件、定时任务
Lambda 的知识点 →

04S3可选

存储组 · Serverless · 按用量 · 售价 $60
在这里
验过的才回源取内容（可选：源站是 S3）
为什么用它
不用规划容量，存多少付多少，数据持久性 11 个 9；越放越冷的数据还能自动转到更便宜的存储类别
它是什么
对象存储：文件当成「对象」放进桶里，按存的数据量和请求次数收费，容量不用提前规划。标准存储类会把数据存到一个区域里至少 3 个 AZ。
常见用法
网站图片和静态资源、数据湖、备份归档、日志
