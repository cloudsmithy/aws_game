每一块干什么5 块服务

01WAF可选

安全组 · 托管服务 · 按用量 · 售价 $400
在这里
WAF 挡在入口过滤恶意请求
为什么用它
在入口按规则拦 SQL 注入、XSS、恶意爬虫和刷接口，不用改应用代码
它是什么
Web 应用防火墙：挂在 CloudFront、ALB、API Gateway 前面，按规则拦 SQL 注入、跨站脚本和恶意机器人，还能按 IP 限速。
常见用法
防常见 Web 攻击、防刷接口
WAF 的知识点 →

02GuardDuty必须

安全组 · 托管服务 · 按用量 · 售价 $380
在这里
GuardDuty 盯着账户和网络里的异常行为
为什么用它
不用装代理，开了就分析 CloudTrail、VPC 流日志和 DNS 日志，发现挖矿、凭证泄露这类异常
它是什么
威胁检测：持续分析 CloudTrail 事件、VPC 流日志和 DNS 日志等，发现挖矿、凭证泄露、异常访问。它只负责发现、不负责拦截，要配合 EventBridge 和 Lambda 自动处置。
常见用法
账户安全监控、自动响应安全事件
GuardDuty 的知识点 →

03Inspector必须

安全组 · 托管服务 · 按用量 · 售价 $380
在这里
Inspector 持续扫 EC2、容器镜像和 Lambda 的漏洞
为什么用它
自动发现 EC2、容器镜像和 Lambda 里的漏洞，新 CVE 出来不用等人去扫
它是什么
自动漏洞扫描：持续扫描 EC2、ECR 里的容器镜像和 Lambda 函数，找出软件漏洞和不该暴露的网络端口，按风险打分。
常见用法
补丁管理、合规检查
Inspector 的知识点 →

04Config必须

监控组 · 按用量 · 按用量 · 售价 $150
在这里
Config 检查配置合不合规
为什么用它
记录资源配置怎么变的，自动检查合不合规
它是什么
配置记录和合规检查：持续记录账户里每个资源的配置和变更历史，用规则检查合不合规（比如 S3 桶有没有公开、EBS 卷有没有加密），不合规的可以自动修正。
常见用法
合规审计、查清楚是谁把配置改坏了、自动把公开的 S3 桶改回私有
Config 的知识点 →

05KMS可选

安全组 · 托管服务 · 按用量 · 售价 $400
在这里
KMS 统一管加密密钥、自动轮换
为什么用它
密钥不用自己保管：存数据的服务都能直接用它加密，谁用了密钥 CloudTrail 都有记录
它是什么
托管的密钥管理：创建和管理加密密钥，S3、EBS、RDS 等服务用它加密数据，密钥不会以明文离开 KMS，每次使用都有 CloudTrail 记录。
常见用法
静态数据加密、控制谁能解密数据
