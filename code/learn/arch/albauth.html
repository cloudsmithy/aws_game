每一块干什么4 块服务

01Cognito必须

安全组 · 托管服务 · 按用量 · 售价 $80
在这里
监听器规则里有一步认证：没登录的先跳到 Cognito 托管登录页
为什么用它
登录这件事不用自己写：密码存储、MFA、找回密码、社交登录都是现成的，还能直接给 API Gateway 和 ALB 做鉴权
它是什么
给你的 App 和网站管用户登录：用户池存账号，负责注册、登录、MFA，登录后发 JWT 令牌；身份池把登录的用户换成临时的亚马逊云科技凭证，App 可以直接访问 S3 这类服务。按月活跃用户（MAU）计费。
常见用法
App 和网站的注册登录、给 API 加登录校验（API Gateway、ALB 都能直接认 Cognito 的令牌）、手机 App 直传文件到 S3

02ELB必须

网络组 · 托管服务 · 按小时 · 售价 $140
在这里
ALB 把用户信息放进请求头转给 EC2 或 ECS
为什么用它
多台后端前面放一个统一入口：自动分流量、绕开坏掉的实例，天生跨 AZ
它是什么
负载均衡：把流量分给后面多台 EC2、容器或 Lambda，自动绕开不健康的；ALB 处理 HTTP/HTTPS，NLB 处理 TCP/UDP。
常见用法
网站和 API 的统一入口、多 AZ 高可用

03EC2必须几选一

计算组 · IaaS · 按小时 · 售价 $100
在这里
ALB 把用户信息放进请求头转给 EC2 或 ECS
为什么用它
要完全掌控操作系统、装特殊软件、跑老应用时用它，机型最全
它是什么
云上的虚拟服务器：自己选 CPU、内存和操作系统，按秒计费，可以用按需、Savings Plans、Spot 等方式买。每台实例在一个 AZ 里，要高可用得在多个 AZ 各放几台，配合 ELB 和 Auto Scaling。
常见用法
跑各种应用、需要完全控制操作系统的场景

03ECS必须几选一

容器组 · 容器 · 按小时 · 售价 $180
在这里
ALB 把用户信息放进请求头转给 EC2 或 ECS
为什么用它
想跑容器又不想学 Kubernetes 时选它，配 Fargate 连机器都不用管
它是什么
亚马逊云科技自己的容器编排服务：告诉它要跑几个任务，它负责调度、替换坏掉的；底层可以用 EC2，也可以用 Fargate（不用管服务器）。
常见用法
微服务、批处理任务
