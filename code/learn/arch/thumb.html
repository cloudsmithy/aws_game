每一块干什么4 块服务

01S3必须

存储组 · Serverless · 按用量 · 售价 $60
在这里
图片上传到 S3
为什么用它
不用规划容量，存多少付多少，数据持久性 11 个 9；越放越冷的数据还能自动转到更便宜的存储类别
它是什么
对象存储：文件当成「对象」放进桶里，按存的数据量和请求次数收费，容量不用提前规划。标准存储类会把数据存到一个区域里至少 3 个 AZ。
常见用法
网站图片和静态资源、数据湖、备份归档、日志
S3 的知识点 →

02EventBridge可选

应用集成组 · Serverless · 按用量 · 售价 $240
在这里
EventBridge 先收到 S3 事件并按规则过滤（只要图片、只要某个目录）再分发
为什么用它
发事件的和处理事件的互不认识：多加一个处理方不用改发送方，还能按时间表触发
它是什么
Serverless 事件总线：把亚马逊云科技服务、自己的应用和 SaaS 发出的事件按规则转给 Lambda、Step Functions 等，也能定时触发。
常见用法
事件驱动架构、跨账户分发事件、定时任务
EventBridge 的知识点 →

03Lambda必须

计算组 · Serverless · 按用量 · 售价 $220
在这里
Lambda 生成缩略图
为什么用它
代码不多、按事件触发的活交给它：不用管服务器和扩容，没请求就不花钱
它是什么
无服务器函数：上传代码，有事件来才运行，按请求次数和运行时长（毫秒）收费，没请求不收钱；单次最长运行 15 分钟。
常见用法
API 后端、处理 S3 上传的文件、定时任务
Lambda 的知识点 →

04CloudFront必须

网络组 · 全局服务 · 按用量 · 售价 $400
在这里
CloudFront 从 S3 取图就近分发
为什么用它
用户分布广、静态内容多时放在最前面：就近返回，源站压力小，还能在边缘挡攻击
它是什么
CDN：把网站、视频和 API 缓存到全球各地的边缘站点，用户就近访问，减轻源站压力；自带 Shield Standard 挡常见的 DDoS。
常见用法
网站和静态资源加速、视频分发
