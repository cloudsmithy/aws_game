每一块干什么3 块服务

01Cognito必须

安全组 · 托管服务 · 按用量 · 售价 $80
在这里
用户先用 Cognito 登录拿到令牌
为什么用它
登录这件事不用自己写：密码存储、MFA、找回密码、社交登录都是现成的，还能直接给 API Gateway 和 ALB 做鉴权
它是什么
给你的 App 和网站管用户登录：用户池存账号，负责注册、登录、MFA，登录后发 JWT 令牌；身份池把登录的用户换成临时的亚马逊云科技凭证，App 可以直接访问 S3 这类服务。按月活跃用户（MAU）计费。
常见用法
App 和网站的注册登录、给 API 加登录校验（API Gateway、ALB 都能直接认 Cognito 的令牌）、手机 App 直传文件到 S3

02AgentCore必须

AI组 · Serverless · 按用量 · 售价 $100
在这里
AgentCore Runtime 只接带有效令牌的请求（入站认证）；AgentCore Identity 知道这一次是谁在用
为什么用它
智能体上生产要的运行隔离、会话记忆、工具网关、身份认证都托管好了，不用自己搭一套
它是什么
Bedrock AgentCore：把 AI 智能体推上生产的托管平台。Runtime 托管运行智能体（LangGraph、CrewAI、Strands 这些框架都能用），每个会话跑在单独的 microVM 里，按实际用的算力计费；Memory、Gateway、Identity、Observability 这些组件按需组合。
常见用法
客服助手、运维助手、能调业务接口的 AI 助理
AgentCore 的知识点 →

03Lambda必须

计算组 · Serverless · 按用量 · 售价 $220
在这里
智能体通过 Gateway 调 Lambda 办事
为什么用它
代码不多、按事件触发的活交给它：不用管服务器和扩容，没请求就不花钱
它是什么
无服务器函数：上传代码，有事件来才运行，按请求次数和运行时长（毫秒）收费，没请求不收钱；单次最长运行 15 分钟。
常见用法
API 后端、处理 S3 上传的文件、定时任务
