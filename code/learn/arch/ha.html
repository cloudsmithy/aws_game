每一块干什么6 块服务

01Route 53必须

网络组 · 全局服务 · 按用量 · 售价 $160
在这里
Route 53 健康检查
为什么用它
域名解析和健康检查一起做：一边挂了自动切到另一边
它是什么
托管的 DNS：注册和解析域名，能按健康检查做故障切换，按延迟或地理位置把用户引到不同区域。全局服务，可用性 SLA 是 100%。
常见用法
域名解析、跨区域容灾切换
Route 53 的知识点 →

02CloudFront可选

网络组 · 全局服务 · 按用量 · 售价 $400
在这里
CloudFront 在边缘接住请求
为什么用它
用户分布广、静态内容多时放在最前面：就近返回，源站压力小，还能在边缘挡攻击
它是什么
CDN：把网站、视频和 API 缓存到全球各地的边缘站点，用户就近访问，减轻源站压力；自带 Shield Standard 挡常见的 DDoS。
常见用法
网站和静态资源加速、视频分发
CloudFront 的知识点 →

03WAF可选

安全组 · 托管服务 · 按用量 · 售价 $400
在这里
WAF 过滤恶意流量
为什么用它
在入口按规则拦 SQL 注入、XSS、恶意爬虫和刷接口，不用改应用代码
它是什么
Web 应用防火墙：挂在 CloudFront、ALB、API Gateway 前面，按规则拦 SQL 注入、跨站脚本和恶意机器人，还能按 IP 限速。
常见用法
防常见 Web 攻击、防刷接口
WAF 的知识点 →

04ELB必须

网络组 · 托管服务 · 按小时 · 售价 $140
在这里
ELB 跨 AZ 分发
为什么用它
多台后端前面放一个统一入口：自动分流量、绕开坏掉的实例，天生跨 AZ
它是什么
负载均衡：把流量分给后面多台 EC2、容器或 Lambda，自动绕开不健康的；ALB 处理 HTTP/HTTPS，NLB 处理 TCP/UDP。
常见用法
网站和 API 的统一入口、多 AZ 高可用
ELB 的知识点 →

05EC2必须

计算组 · IaaS · 按小时 · 售价 $100
在这里
EC2 跑应用；EC2 放私有子网
为什么用它
要完全掌控操作系统、装特殊软件、跑老应用时用它，机型最全
它是什么
云上的虚拟服务器：自己选 CPU、内存和操作系统，按秒计费，可以用按需、Savings Plans、Spot 等方式买。每台实例在一个 AZ 里，要高可用得在多个 AZ 各放几台，配合 ELB 和 Auto Scaling。
常见用法
跑各种应用、需要完全控制操作系统的场景
EC2 的知识点 →

06VPC可选

网络组 · 托管服务 · 免费 · 售价 $140
在这里
自己的 VPC 划好跨 AZ 的公有、私有子网
为什么用它
把资源放进自己的私有网络，子网和安全组决定谁能访问，数据库不用暴露在公网上
它是什么
你在云上的私有网络：自己划网段、子网、路由表和安全组，决定哪些资源能访问公网。VPC 本身不收费。
常见用法
把对外的负载均衡放公有子网，应用和数据库放私有子网
