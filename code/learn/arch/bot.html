每一块干什么6 块服务

01Cognito可选

安全组 · 托管服务 · 按用量 · 售价 $80
在这里
用户先用 Cognito 登录
为什么用它
登录这件事不用自己写：密码存储、MFA、找回密码、社交登录都是现成的，还能直接给 API Gateway 和 ALB 做鉴权
它是什么
给你的 App 和网站管用户登录：用户池存账号，负责注册、登录、MFA，登录后发 JWT 令牌；身份池把登录的用户换成临时的亚马逊云科技凭证，App 可以直接访问 S3 这类服务。按月活跃用户（MAU）计费。
常见用法
App 和网站的注册登录、给 API 加登录校验（API Gateway、ALB 都能直接认 Cognito 的令牌）、手机 App 直传文件到 S3

02API Gateway必须

网络组 · Serverless · 按用量 · 售价 $220
在这里
API Gateway 收消息
为什么用它
不用自己搭网关：鉴权、限流、缓存、版本管理开箱就有，后面直接接 Lambda
它是什么
托管的 API 入口：创建 REST、HTTP、WebSocket API，负责鉴权、限流和缓存，后面接 Lambda 或其他服务，按调用次数收费。
常见用法
Serverless API、移动应用和小程序后端
API Gateway 的知识点 →

03Lambda必须

计算组 · Serverless · 按用量 · 售价 $220
在这里
Lambda 组装提示词和上下文
为什么用它
代码不多、按事件触发的活交给它：不用管服务器和扩容，没请求就不花钱
它是什么
无服务器函数：上传代码，有事件来才运行，按请求次数和运行时长（毫秒）收费，没请求不收钱；单次最长运行 15 分钟。
常见用法
API 后端、处理 S3 上传的文件、定时任务
Lambda 的知识点 →

04AgentCore可选

AI组 · Serverless · 按用量 · 售价 $100
在这里
交给 AgentCore 上跑的智能体
为什么用它
智能体上生产要的运行隔离、会话记忆、工具网关、身份认证都托管好了，不用自己搭一套
它是什么
Bedrock AgentCore：把 AI 智能体推上生产的托管平台。Runtime 托管运行智能体（LangGraph、CrewAI、Strands 这些框架都能用），每个会话跑在单独的 microVM 里，按实际用的算力计费；Memory、Gateway、Identity、Observability 这些组件按需组合。
常见用法
客服助手、运维助手、能调业务接口的 AI 助理

05Bedrock必须几选一

AI组 · 按 token 计费 · 按 token · 售价 $500
在这里
Bedrock 或 SageMaker AI 上部署的模型生成回答
为什么用它
想直接用现成的大模型时选它：一个 API 调多家模型，不用管 GPU，按 token 付费
它是什么
用 API 调用多家公司的基础模型（Anthropic Claude、Amazon Nova、Meta Llama、Mistral 等），按输入输出的 token 收费；还有知识库、Agents、Guardrails。你的数据不会被拿去训练模型。
常见用法
聊天机器人、内容生成、AI Agent

05SageMaker AI必须几选一

AI组 · PaaS · 按小时 · 售价 $460
在这里
Bedrock 或 SageMaker AI 上部署的模型生成回答
为什么用它
要自己训练、微调或部署模型时用它：训练、调参、上线、监控在一个平台里
它是什么
机器学习平台：在上面准备数据、训练、调参和部署模型，有托管的 Notebook 环境，推理端点按实例时长收费。
常见用法
训练自己的模型、部署推理服务
