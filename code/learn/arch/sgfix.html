每一块干什么3 块服务

01EC2必须

计算组 · IaaS · 按小时 · 售价 $100
在这里
EC2 的安全组被人改成对 0.0.0.0/0 开 22 端口
为什么用它
安全组挂在 EC2 上，对 0.0.0.0/0 开着 22、3389 端口，是最常见的被入侵入口
它是什么
云上的虚拟服务器：自己选 CPU、内存和操作系统，按秒计费，可以用按需、Savings Plans、Spot 等方式买。每台实例在一个 AZ 里，要高可用得在多个 AZ 各放几台，配合 ELB 和 Auto Scaling。
常见用法
跑各种应用、需要完全控制操作系统的场景

02Config必须

监控组 · 按用量 · 按用量 · 售价 $150
在这里
Config 规则 restricted-ssh 发现了
为什么用它
记录资源配置怎么变的，自动检查合不合规
它是什么
配置记录和合规检查：持续记录账户里每个资源的配置和变更历史，用规则检查合不合规（比如 S3 桶有没有公开、EBS 卷有没有加密），不合规的可以自动修正。
常见用法
合规审计、查清楚是谁把配置改坏了、自动把公开的 S3 桶改回私有

03EventBridge必须

应用集成组 · Serverless · 按用量 · 售价 $240
在这里
EventBridge 把这件事通知到安全团队
为什么用它
发事件的和处理事件的互不认识：多加一个处理方不用改发送方，还能按时间表触发
它是什么
Serverless 事件总线：把亚马逊云科技服务、自己的应用和 SaaS 发出的事件按规则转给 Lambda、Step Functions 等，也能定时触发。
常见用法
事件驱动架构、跨账户分发事件、定时任务
