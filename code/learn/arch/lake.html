每一块干什么4 块服务

01Kinesis可选

分析组 · 托管服务 · 按小时 · 售价 $300
在这里
Kinesis 把网站和 App 的点击流实时写进来
为什么用它
数据一条条持续进来、要实时处理时用它：扛得住突发流量，多个消费者能同时读
它是什么
实时数据流：Kinesis Data Streams 接住每秒大量的事件，多个程序同时读；Data Firehose 能把数据直接送进 S3、Redshift、OpenSearch。
常见用法
点击流和日志实时分析、实时大屏、IoT 数据
Kinesis 的知识点 →

02S3必须

存储组 · Serverless · 按用量 · 售价 $60
在这里
S3 按小时分区存原始数据
为什么用它
不用规划容量，存多少付多少，数据持久性 11 个 9；越放越冷的数据还能自动转到更便宜的存储类别
它是什么
对象存储：文件当成「对象」放进桶里，按存的数据量和请求次数收费，容量不用提前规划。标准存储类会把数据存到一个区域里至少 3 个 AZ。
常见用法
网站图片和静态资源、数据湖、备份归档、日志
S3 的知识点 →

03Glue必须

分析组 · Serverless · 按用量 · 售价 $300
在这里
Glue 爬虫识别表结构、建好数据目录
为什么用它
清洗数据、转格式、建数据目录不用自己搭集群，按运行时间付费
它是什么
Serverless 的数据集成（ETL）服务：爬取数据源建数据目录，用 Spark 作业清洗、转换数据，按运行时长收费。
常见用法
数据湖入湖、给 Athena 和 Redshift 准备数据
Glue 的知识点 →

04Athena必须

分析组 · Serverless · 按用量 · 售价 $320
在这里
Athena 直接用 SQL 查
为什么用它
偶尔查一查 S3 里的数据时最省事：不用建库、不用管服务器，按扫描的数据量付费
它是什么
Serverless 交互式查询：直接用 SQL 查 S3 里的数据，不用建集群，按扫描的数据量收费。数据存成列式格式、按日期分区，能少扫很多、省钱。
常见用法
日志分析、数据湖临时查询
