每一块干什么4 块服务

01CloudFront必须

网络组 · 全局服务 · 按用量 · 售价 $400
在这里
CloudFront 在边缘接住请求
为什么用它
用户分布广、静态内容多时放在最前面：就近返回，源站压力小，还能在边缘挡攻击
它是什么
CDN：把网站、视频和 API 缓存到全球各地的边缘站点，用户就近访问，减轻源站压力；自带 Shield Standard 挡常见的 DDoS。
常见用法
网站和静态资源加速、视频分发
CloudFront 的知识点 →

02WAF必须

安全组 · 托管服务 · 按用量 · 售价 $400
在这里
WAF 过滤恶意流量
为什么用它
在入口按规则拦 SQL 注入、XSS、恶意爬虫和刷接口，不用改应用代码
它是什么
Web 应用防火墙：挂在 CloudFront、ALB、API Gateway 前面，按规则拦 SQL 注入、跨站脚本和恶意机器人，还能按 IP 限速。
常见用法
防常见 Web 攻击、防刷接口
WAF 的知识点 →

03API Gateway必须

网络组 · Serverless · 按用量 · 售价 $220
在这里
API Gateway 处理
为什么用它
不用自己搭网关：鉴权、限流、缓存、版本管理开箱就有，后面直接接 Lambda
它是什么
托管的 API 入口：创建 REST、HTTP、WebSocket API，负责鉴权、限流和缓存，后面接 Lambda 或其他服务，按调用次数收费。
常见用法
Serverless API、移动应用和小程序后端
API Gateway 的知识点 →

04Lambda可选

计算组 · Serverless · 按用量 · 售价 $220
在这里
Lambda 跑后端逻辑
为什么用它
代码不多、按事件触发的活交给它：不用管服务器和扩容，没请求就不花钱
它是什么
无服务器函数：上传代码，有事件来才运行，按请求次数和运行时长（毫秒）收费，没请求不收钱；单次最长运行 15 分钟。
常见用法
API 后端、处理 S3 上传的文件、定时任务
