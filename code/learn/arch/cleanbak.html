每一块干什么4 块服务

01EBS必须

存储组 · IaaS · 按小时 · 售价 $120
在这里
EBS 快照开快照锁定（合规模式下到期前谁都删不掉，root 用户也不行）
为什么用它
EBS 快照存在 S3 里，配上快照锁定，勒索软件拿到权限也删不掉备份
它是什么
给 EC2 用的块存储（云硬盘）：一块卷挂在同一个 AZ 的实例上当系统盘或数据盘，可以打快照备份。卷只在一个 AZ 里。
常见用法
系统盘、自建数据库的数据盘
EBS 的知识点 →

02S3必须

存储组 · Serverless · 按用量 · 售价 $60
在这里
重要文件放进开了对象锁定的 S3 桶
为什么用它
不用规划容量，存多少付多少，数据持久性 11 个 9；越放越冷的数据还能自动转到更便宜的存储类别
它是什么
对象存储：文件当成「对象」放进桶里，按存的数据量和请求次数收费，容量不用提前规划。标准存储类会把数据存到一个区域里至少 3 个 AZ。
常见用法
网站图片和静态资源、数据湖、备份归档、日志
S3 的知识点 →

03GuardDuty必须

安全组 · 托管服务 · 按用量 · 售价 $380
在这里
GuardDuty 恶意软件防护扫描 EBS 卷和新传进 S3 的文件
为什么用它
不用装代理，开了就分析 CloudTrail、VPC 流日志和 DNS 日志，发现挖矿、凭证泄露这类异常
它是什么
威胁检测：持续分析 CloudTrail 事件、VPC 流日志和 DNS 日志等，发现挖矿、凭证泄露、异常访问。它只负责发现、不负责拦截，要配合 EventBridge 和 Lambda 自动处置。
常见用法
账户安全监控、自动响应安全事件
GuardDuty 的知识点 →

04KMS可选

安全组 · 托管服务 · 按用量 · 售价 $400
在这里
KMS 客户托管密钥加密快照和对象
为什么用它
密钥不用自己保管：存数据的服务都能直接用它加密，谁用了密钥 CloudTrail 都有记录
它是什么
托管的密钥管理：创建和管理加密密钥，S3、EBS、RDS 等服务用它加密数据，密钥不会以明文离开 KMS，每次使用都有 CloudTrail 记录。
常见用法
静态数据加密、控制谁能解密数据
