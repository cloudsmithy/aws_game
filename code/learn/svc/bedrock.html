核心知识点5 条

  1. 全托管的生成式 AI 服务：一个 API 调多家基础模型（Anthropic Claude、Amazon Nova、Meta Llama、Mistral 等）
  2. 按输入、输出 token 计费；用量大可以买预置吞吐量
  3. Knowledge Bases 做 RAG：把 S3 里的资料切块、向量化，存进向量库（OpenSearch Serverless、Aurora PostgreSQL 等）
  4. Guardrails 过滤有害内容和敏感信息；Agents 能调工具、执行多步任务
  5. 你的提示词和数据不会被拿去训练基础模型

答对 0 / 8，已答 0

1.Amazon Bedrock 是做什么的？
答案用 API 调用多家基础模型的托管服务
按输入和输出的 token 数收费，也可以买按小时计费的预置吞吐
2.Bedrock Knowledge Bases 主要用于？
答案检索增强生成（RAG）
把你的资料接到模型上做检索增强
3.Bedrock 的跨区域推理是做什么的？
答案把请求分到多个 Region 处理，扛住突发流量
地理跨区域推理只在美国、欧盟这类范围内分流，全球跨区域推理分到全球、约省 10%；本 Region 出问题照样调不通
4.Bedrock Guardrails 用来做什么？
答案过滤有害内容、屏蔽敏感信息
可以挂在不同模型前面统一使用
5.Bedrock Knowledge Bases 用户上传的资料存在哪里检索？
答案向量数据库，比如 OpenSearch Serverless
资料切块后转成向量存起来，提问时先检索再生成
6.有几十万条商品描述要让模型改写，几天内出结果就行。Bedrock 用哪种方式最合适？
答案批量推理：提交作业，结果写进 S3
比按需便宜 50%，但不保证完成时间；作业默认 24 小时超时，最长可设 168 小时
7.每次调用都带着同一大段系统提示词和参考文档，Bedrock 用什么功能能省输入费、又能降延迟？
答案提示缓存（Prompt caching）
重复的长上下文缓存起来，后面的请求不用重新处理；支持哪些模型要看文档
8.想让一个更小、更便宜的模型在自己的业务场景里接近大模型的效果，Bedrock 用什么？
答案模型蒸馏：大模型当老师教小模型
大模型生成合成数据，再拿来微调小模型；之后调用小模型，更快也更便宜
