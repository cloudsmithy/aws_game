Route 53

网络组全局服务按用量全局服务

托管的 DNS：注册和解析域名，能按健康检查做故障切换，按延迟或地理位置把用户引到不同区域。全局服务，可用性 SLA 是 100%。

常见用法

域名解析、跨区域容灾切换

为什么用它

域名解析和健康检查一起做：一边挂了自动切到另一边

核心知识点5 条

  1. 托管 DNS 加域名注册，服务等级协议（SLA）承诺 100% 可用
  2. 路由策略：简单、加权、延迟、故障转移、地理位置、地理邻近、多值应答
  3. 健康检查配故障转移路由：主站点挂了，自动把用户切到备用站点
  4. 别名记录（Alias）能直接指向 ELB、CloudFront、S3 静态网站等，这类查询不收费
  5. 私有托管区只在关联的 VPC 里能解析
