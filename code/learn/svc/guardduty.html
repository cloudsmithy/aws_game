SERVICE安全组 · 托管服务

GuardDuty

安全组托管服务按用量自带跨 AZ 高可用

威胁检测：持续分析 CloudTrail 事件、VPC 流日志和 DNS 日志等，发现挖矿、凭证泄露、异常访问。它只负责发现、不负责拦截，要配合 EventBridge 和 Lambda 自动处置。

常见用法

账户安全监控、自动响应安全事件

为什么用它

不用装代理，开了就分析 CloudTrail、VPC 流日志和 DNS 日志，发现挖矿、凭证泄露这类异常

核心知识点5 条

  1. 威胁检测：分析 CloudTrail 管理事件、VPC 流日志、DNS 日志，不用装代理
  2. 能加开的保护：S3、EKS 审计日志、运行时监控、恶意软件扫描、RDS 登录活动、Lambda 网络活动
  3. 发现（finding）按严重程度分级，能发到 EventBridge 自动处置
  4. 多账户用委派管理员账户统一管理
  5. 用机器学习和威胁情报识别挖矿、凭证泄露、异常 API 调用这类行为

1.GuardDuty 主要分析哪些数据？
答案CloudTrail、VPC 流日志、DNS 日志等
基础检测开启即可，不用自己部署采集；运行时监控要装代理，可以自动管理
2.GuardDuty 发现异常后，想自动隔离实例，常见做法是？
答案EventBridge 规则触发 Lambda 处置
也可以触发 Step Functions 编排多步处置，这就是「威胁自动响应」架构
3.安全团队想持续分析账户中的日志和数据源，利用威胁情报和机器学习发现可疑活动，比如与已知恶意 IP 的通信。应使用哪项服务？CLF-C02
答案Amazon GuardDuty
GuardDuty 是威胁检测服务，持续监控和分析环境中的数据源与日志，结合威胁情报和机器学习识别威胁。Certificate Manager 管理 SSL/TLS 证书，不做威胁检测。　官方文档 ↗
