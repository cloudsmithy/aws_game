Config

监控组按用量按用量万能服务

配置记录和合规检查：持续记录账户里每个资源的配置和变更历史，用规则检查合不合规（比如 S3 桶有没有公开、EBS 卷有没有加密），不合规的可以自动修正。

常见用法

合规审计、查清楚是谁把配置改坏了、自动把公开的 S3 桶改回私有

为什么用它

记录资源配置怎么变的，自动检查合不合规

核心知识点5 条

  1. 记录资源的配置和变化历史：某个安全组什么时候被谁改成了什么
  2. Config 规则（托管的或自己写的）持续检查资源合不合规，比如「S3 桶不能公开」「EBS 卷必须加密」
  3. 不合规的可以自动修正（调用 Systems Manager 自动化文档）
  4. 合规包把一组规则打包部署；聚合器汇总多个账户、多个区域的合规情况
  5. 按记录的配置项数量和规则评估次数计费

三个关键功能游戏里的三级升级，就是现实里的这三个功能

自动修正

游戏里：免疫「有人手动改了生产配置」；免疫「S3 桶被设成了公开」
