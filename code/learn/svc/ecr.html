服务知识点/容器组/ECR

SERVICE容器组 · 托管服务

ECR

容器组托管服务按用量自带跨 AZ 高可用

托管的容器镜像仓库：存放 Docker / OCI 镜像，可以扫描漏洞，ECS、EKS 直接从这里拉镜像。

常见用法

CI/CD 构建完镜像推上去，部署时拉下来

为什么用它

镜像就放在部署的地方旁边：和 ECS、EKS 权限打通，推送时顺手扫漏洞

核心知识点5 条

  1. 托管的容器镜像仓库，存 Docker 镜像和 OCI 制品（比如 Helm chart）
  2. 用 IAM 控制谁能推、谁能拉；ECS、EKS、Lambda（容器镜像部署）直接从这里拉
  3. 镜像扫描：基础扫描，或者交给 Inspector 做增强扫描，新 CVE 出来持续重扫
  4. 生命周期策略自动清掉旧镜像；能跨区域、跨账户复制
  5. 标签设成不可变，同一个标签就不会被新镜像覆盖
