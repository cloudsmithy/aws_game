Redshift

分析组PaaS按小时要自己做多 AZ

云数据仓库：列式存储、大规模并行处理，用 SQL 分析海量数据；有预置集群和 Redshift Serverless 两种用法。

常见用法

BI 报表、经营分析

为什么用它

数据量大、报表和复杂 SQL 多时用它：列式存储加大规模并行，几十亿行也查得动

核心知识点5 条

  1. 云数据仓库：列式存储加大规模并行处理（MPP），适合复杂 SQL 分析和报表
  2. 两种用法：预置集群（RA3 节点，计算和存储分开扩）和 Redshift Serverless（按用量计费）
  3. Redshift Spectrum 直接查 S3 里的数据；Zero-ETL 集成从 Aurora、RDS、DynamoDB 近实时同步
  4. 流式摄取能直接从 Kinesis、MSK 读数据
  5. 数据共享让多个集群用同一份数据，不用来回复制

三个关键功能游戏里的三级升级，就是现实里的这三个功能

和谁比、怎么选

OpenSearch 还是 Redshift

要全文检索、日志实时搜索，选 OpenSearch；要大规模 SQL 分析和报表，选 Redshift

OpenSearch 还是 Redshift 还是 S3

便宜地长期存、离线分析，放 S3 数据湖；要秒级 SQL 报表，进 Redshift；要实时检索，进 OpenSearch

1.Redshift Spectrum 可以做什么？
答案直接查询 S3 上的数据
不用先把数据导入 Redshift
2.Redshift 是行式存储还是列式存储？
答案列式
列式存储适合分析型查询
3.Redshift Serverless 怎么收费？
答案按用到的 RPU 小时
RPU 是计算容量单位；没有查询时不收计算费，存储另算
4.分析团队需要一个全托管、PB 级的云上数据仓库，对海量历史销售数据运行复杂分析查询。应选择哪项服务？CLF-C02
答案Amazon Redshift
Redshift 是全托管、PB 级的云数据仓库服务，还提供无服务器选项。DynamoDB 适合高并发的键值和文档读写，不是为复杂分析查询设计的数据仓库。　官方文档 ↗
