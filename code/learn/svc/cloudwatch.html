CloudWatch

监控组按用量按用量万能服务

监控和可观测性：收集指标、日志和事件，设告警、做仪表板，告警可以通知人，也能触发 Auto Scaling 自动扩容。

常见用法

盯 CPU、错误率和延迟，出事自动告警

为什么用它

指标、日志、告警都在这里，出问题第一时间知道

核心知识点5 条

  1. 指标：服务自动上报，也能发自定义指标；告警超过阈值就通知，或者触发 Auto Scaling 这类动作
  2. 日志：集中收应用和服务的日志，Logs Insights 用查询语言分析
  3. 仪表板汇总展示；Synthetics 用脚本模拟用户访问，提前发现故障
  4. Container Insights、Lambda Insights、Application Signals 看应用健康
  5. 按指标数、日志量、告警数等计费
