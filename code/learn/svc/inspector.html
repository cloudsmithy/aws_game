Inspector

安全组托管服务按用量自带跨 AZ 高可用

自动漏洞扫描：持续扫描 EC2、ECR 里的容器镜像和 Lambda 函数，找出软件漏洞和不该暴露的网络端口，按风险打分。

常见用法

补丁管理、合规检查

为什么用它

自动发现 EC2、容器镜像和 Lambda 里的漏洞，新 CVE 出来不用等人去扫

核心知识点5 条

  1. 自动、持续的漏洞管理：扫描 EC2、ECR 容器镜像、Lambda 函数里的软件漏洞（CVE）和网络暴露
  2. 有新 CVE 公布或软件包变了，自动重新评估，不用定时手动扫
  3. 风险评分结合漏洞严重程度和实际暴露情况，先修最要紧的
  4. EC2 扫描靠 SSM Agent，也可以无代理扫描（基于 EBS 快照）
  5. 发现能汇总到 Security Hub、发到 EventBridge；能导出软件物料清单（SBOM）
