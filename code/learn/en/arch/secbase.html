What each piece does5 services

01WAFOptional

Security group · Managed · By usage · Price $400
Role here
WAF filters malicious requests at the entry point
Why use it
Blocks SQL injection, XSS, malicious bots and API abuse with rules at the entry point, without changing application code
What it is
Web application firewall: sits in front of CloudFront, ALB, or API Gateway and blocks SQL injection, cross-site scripting, and malicious bots by rule. It can also rate-limit by IP.
Common uses
Defending against common web attacks, preventing API abuse
WAF service notes →

02GuardDutyRequired

Security group · Managed · By usage · Price $380
Role here
GuardDuty watches for abnormal behavior in the account and network
Why use it
No agents to install: once it's on, it analyzes CloudTrail, VPC Flow Logs and DNS logs to find anomalies such as crypto mining and leaked credentials
What it is
Threat detection: continuously analyzes CloudTrail events, VPC Flow Logs, DNS logs and more to find crypto mining, leaked credentials, and unusual access. It only detects and does not block, so pair it with EventBridge and Lambda for automated response.
Common uses
Account security monitoring, automated response to security events
GuardDuty service notes →

03InspectorRequired

Security group · Managed · By usage · Price $380
Role here
Inspector continuously scans EC2, container images, and Lambda for vulnerabilities
Why use it
Finds vulnerabilities in EC2, container images and Lambda automatically, so when a new CVE comes out, you don't have to wait for someone to run a scan
What it is
Automated vulnerability scanning: continuously scans EC2 instances, container images in ECR, and Lambda functions for software vulnerabilities and unintended network exposure, and scores them by risk.
Common uses
Patch management, compliance checks
Inspector service notes →

04ConfigRequired

Monitoring group · By usage · By usage · Price $150
Role here
Config checks whether configurations are compliant and automatically fixes non-compliant ones
Why use it
Records how resource configurations change and checks compliance automatically
What it is
Configuration recording and compliance checks: continuously records the configuration and change history of every resource in your account, and checks compliance with rules (for example, whether an S3 bucket is public or an EBS volume is encrypted). Noncompliant resources can be remediated automatically.
Common uses
Compliance auditing, finding out who broke a configuration, automatically making a public S3 bucket private again
Config service notes →

05KMSOptional

Security group · Managed · By usage · Price $400
Role here
KMS manages encryption keys centrally with automatic rotation
Why use it
You don't have to keep keys yourself: services that store data can use it directly for encryption, and CloudTrail records who used each key
What it is
Managed key management: create and manage encryption keys that S3, EBS, RDS and other services use to encrypt data. Keys never leave KMS in plaintext, and every use is logged in CloudTrail.
Common uses
Encrypting data at rest, controlling who can decrypt data
