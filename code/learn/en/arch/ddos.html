What each piece does4 services

01CloudFrontRequiredOne of

Networking group · Global service · By usage · Price $400
Role here
A CloudFront distribution or ALB is added to Shield Advanced protection
Why use it
Put it at the very front when users are spread out and there's a lot of static content: responses come from nearby, the origin carries less load, and attacks can be blocked at the edge
What it is
CDN: caches your website, video and APIs at edge locations around the world so users connect to the nearest one, which takes load off the origin. Comes with Shield Standard against common DDoS attacks.
Common uses
Speeding up websites and static assets, video delivery
CloudFront service notes →

01ELBRequiredOne of

Networking group · Managed · By the hour · Price $140
Role here
A CloudFront distribution or ALB is added to Shield Advanced protection
Why use it
One entry point in front of multiple backends: it spreads traffic automatically, routes around failed instances, and spans AZs by design
What it is
Load balancing: spreads traffic across multiple EC2 instances, containers or Lambda functions behind it and automatically routes around unhealthy ones; ALB handles HTTP/HTTPS and NLB handles TCP/UDP.
Common uses
A single entry point for websites and APIs, Multi-AZ high availability
ELB service notes →
How to choose

For global users and lots of static content, attach Shield to CloudFront; for a single Region with mostly dynamic requests, attach it to ALB

02Shield AdvancedRequired

Security group · Global service · Subscription · Price $420
Role here
A CloudFront distribution or ALB is added to Shield Advanced protection
Why use it
Withstands large DDoS attacks: an expert team responds around the clock, and you can request credits for the extra scaling costs incurred during an attack
What it is
DDoS protection: Shield Standard is included free on every account and blocks common network-layer attacks. Shield Advanced is a paid subscription that adds application-layer protection, Shield Response Team (SRT) support, and credits for scaling costs during an attack.
Common uses
Large websites, games, and financial workloads that are sensitive to DDoS
Shield Advanced service notes →

03WAFRequired

Security group · Managed · By usage · Price $400
Role here
To defend against application-layer attacks, associate a WAF Web ACL with this entry point and include at least one rate-based rule
Why use it
Blocks SQL injection, XSS, malicious bots and API abuse with rules at the entry point, without changing application code
What it is
Web application firewall: sits in front of CloudFront, ALB, or API Gateway and blocks SQL injection, cross-site scripting, and malicious bots by rule. It can also rate-limit by IP.
Common uses
Defending against common web attacks, preventing API abuse
