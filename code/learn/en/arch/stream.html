What each piece does4 services

01KinesisRequired

Analytics group · Managed · By the hour · Price $300
Role here
Kinesis receives the data stream
Why use it
Use it when records keep streaming in and must be processed in real time: it handles traffic bursts, and multiple consumers can read at the same time
What it is
Real-time data streaming: Kinesis Data Streams absorbs large numbers of events per second and lets multiple applications read at once; Data Firehose can deliver data straight into S3, Redshift and OpenSearch.
Common uses
Real-time analysis of clickstreams and logs, live dashboards, IoT data
Kinesis service notes →

02LambdaRequired

Compute group · Serverless · By usage · Price $220
Role here
Lambda processes it and writes it into OpenSearch for search
Why use it
Give it small, event-triggered jobs: no servers or scaling to manage, and no requests means no cost
What it is
Serverless functions: upload code and it runs only when an event arrives, billed by number of requests and run time (in milliseconds), with no charge when there are no requests; a single run can last up to 15 minutes.
Common uses
API backends, processing files uploaded to S3, scheduled tasks
Lambda service notes →

03OpenSearchRequiredOne of

Analytics group · PaaS · By the hour · Price $360
Role here
Lambda processes it and writes it into OpenSearch for search
Why use it
Use it for full-text search, fuzzy matching and real-time log search, which are slow on a relational database and put load on it
What it is
Managed OpenSearch (the open-source project forked from Elasticsearch): full-text search, log analytics and visualization, and it can also serve as a vector database.
Common uses
Site search, log search, vector search for RAG
OpenSearch service notes →

03RedshiftRequiredOne of

Analytics group · PaaS · By the hour · Price $340
Role here
Redshift can also ingest streams from Kinesis directly and analyze them with SQL
Why use it
Use it for large data volumes with lots of reports and complex SQL: columnar storage plus massively parallel processing can query billions of rows
What it is
Cloud data warehouse: columnar storage and massively parallel processing, analyzing huge amounts of data with SQL; available as provisioned clusters or Redshift Serverless.
Common uses
BI reports and business analytics
Redshift service notes →
How to choose

For full-text search and real-time log search, choose OpenSearch; for large-scale SQL analytics and reports, choose Redshift
