What each piece does3 services

01Step FunctionsRequired

Application Integration group · Serverless · By usage · Price $260
Role here
Step Functions orchestrates the multi-step task
Why use it
No need to write your own state machine for multi-step processes: retries, timeouts and rollback on failure can be configured for each step, and you can see which step a run has reached
What it is
Visual workflow orchestration: chains Lambda, container tasks and API calls to many services into a state machine, with built-in retries, branching and parallelism, and can pause to wait for human approval.
Common uses
Order processing flows, data processing pipelines, orchestrating the steps of AI agents
Step Functions service notes →

02LambdaRequired

Compute group · Serverless · By usage · Price $220
Role here
Lambda calls tools and APIs
Why use it
Give it small, event-triggered jobs: no servers or scaling to manage, and no requests means no cost
What it is
Serverless functions: upload code and it runs only when an event arrives, billed by number of requests and run time (in milliseconds), with no charge when there are no requests; a single run can last up to 15 minutes.
Common uses
API backends, processing files uploaded to S3, scheduled tasks
Lambda service notes →

03BedrockRequired

AI group · Billed per token · Per token · Price $500
Role here
Bedrock inference decides the next step
Why use it
Choose it when you want to use ready-made large models directly: one API for models from many providers, no GPUs to manage, and you pay per token
What it is
Call foundation models from multiple companies (Anthropic Claude, Amazon Nova, Meta Llama, Mistral, and more) through an API, billed per input and output token. Also includes Knowledge Bases, Agents, and Guardrails. Your data is not used to train models.
Common uses
Chatbots, content generation, AI agents
