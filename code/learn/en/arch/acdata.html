What each piece does3 services

01AgentCoreRequired

AI group · Serverless · By usage · Price $100
Role here
An AgentCore agent writes SQL, and uses Code Interpreter to run analysis and draw charts
Why use it
The runtime isolation, session memory, tool gateway and identity that agents need in production are all managed, so you don't have to build them yourself
What it is
Bedrock AgentCore: a managed platform for taking AI agents to production. Runtime hosts and runs agents (frameworks such as LangGraph, CrewAI and Strands all work), each session runs in its own microVM, and you are billed for the compute actually used; components such as Memory, Gateway, Identity and Observability can be combined as needed.
Common uses
Customer service assistants, operations assistants, AI assistants that can call business APIs

02AthenaRequired

Analytics group · Serverless · By usage · Price $320
Role here
Athena queries the data in S3 directly
Why use it
The easiest way to query data in S3 now and then: no database to set up, no servers to manage, and you pay for the data scanned
What it is
Serverless interactive query: query data in S3 directly with SQL, with no cluster to build, billed by the amount of data scanned. Storing data in columnar formats and partitioning by date means far less is scanned, which saves money.
Common uses
Log analysis, ad hoc data lake queries
Athena service notes →

03S3Required

Storage group · Serverless · By usage · Price $60
Role here
Athena queries the data in S3 directly
Why use it
You don't need to plan capacity, you pay for what you store, and durability is 11 nines; data that gets colder over time can move automatically to cheaper storage classes
What it is
Object storage: files are stored as “objects” in buckets and billed by the amount of data stored and the number of requests, with no capacity planning. The Standard storage class stores data across at least 3 AZs in one Region.
Common uses
Website images and static assets, data lakes, backup and archive, logs
