What each piece does3 services

01EventBridgeRequired

Application Integration group · Serverless · By usage · Price $240
Role here
EventBridge Scheduler triggers on a schedule (for example, start at 9:00 and stop at 20:00 on weekdays)
Why use it
Event senders and event handlers don't need to know each other: adding a handler doesn't require changing the sender, and it can also trigger on a schedule
What it is
Serverless event bus: routes events from Amazon Web Services services, your own applications and SaaS to Lambda, Step Functions and others by rule, and can also trigger on a schedule.
Common uses
Event-driven architectures, distributing events across accounts, scheduled tasks
EventBridge service notes →

02LambdaRequired

Compute group · Serverless · By usage · Price $220
Role here
Lambda calls StartInstances and StopInstances (you can also use the Scheduler universal target to call the EC2 API directly, with no Lambda)
Why use it
Give it small, event-triggered jobs: no servers or scaling to manage, and no requests means no cost
What it is
Serverless functions: upload code and it runs only when an event arrives, billed by number of requests and run time (in milliseconds), with no charge when there are no requests; a single run can last up to 15 minutes.
Common uses
API backends, processing files uploaded to S3, scheduled tasks
Lambda service notes →

03EC2Required

Compute group · IaaS · By the hour · Price $100
Role here
EC2 for dev and test runs only during work hours
Why use it
Development and test environments sit unused at night and on weekends, and a stopped EC2 instance isn't charged for compute (EBS volumes are still charged)
What it is
Virtual servers in the cloud: you pick CPU, memory and operating system, billed by the second, and you can buy them On-Demand, with Savings Plans, as Spot and more. Each instance lives in one AZ, so for high availability you place several in multiple AZs, together with ELB and Auto Scaling.
Common uses
Running all kinds of applications, cases that need full control of the operating system
