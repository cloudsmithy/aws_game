What each piece does3 services

01S3Required

Storage group · Serverless · By usage · Price $60
Role here
Raw data lands in S3
Why use it
You don't need to plan capacity, you pay for what you store, and durability is 11 nines; data that gets colder over time can move automatically to cheaper storage classes
What it is
Object storage: files are stored as “objects” in buckets and billed by the amount of data stored and the number of requests, with no capacity planning. The Standard storage class stores data across at least 3 AZs in one Region.
Common uses
Website images and static assets, data lakes, backup and archive, logs
S3 service notes →

02GlueRequired

Analytics group · Serverless · By usage · Price $300
Role here
Glue jobs clean and transform it
Why use it
Clean data, convert formats and build a data catalog without running your own cluster, and pay for run time
What it is
Serverless data integration (ETL) service: crawls data sources to build a data catalog, cleans and transforms data with Spark jobs, and is billed by run time.
Common uses
Loading a data lake, preparing data for Athena and Redshift
Glue service notes →

03RedshiftRequired

Analytics group · PaaS · By the hour · Price $340
Role here
loaded into Redshift for reports and BI analysis
Why use it
Use it for large data volumes with lots of reports and complex SQL: columnar storage plus massively parallel processing can query billions of rows
What it is
Cloud data warehouse: columnar storage and massively parallel processing, analyzing huge amounts of data with SQL; available as provisioned clusters or Redshift Serverless.
Common uses
BI reports and business analytics
