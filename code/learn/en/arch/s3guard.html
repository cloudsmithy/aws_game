What each piece does3 services

01S3Required

Storage group · Serverless · By usage · Price $60
Role here
An S3 bucket is set to public
Why use it
A bucket accidentally made public is one of the most common causes of data leaks, so it needs to be checked and closed automatically
What it is
Object storage: files are stored as “objects” in buckets and billed by the amount of data stored and the number of requests, with no capacity planning. The Standard storage class stores data across at least 3 AZs in one Region.
Common uses
Website images and static assets, data lakes, backup and archive, logs
S3 service notes →

02ConfigRequired

Monitoring group · By usage · By usage · Price $150
Role here
A Config managed rule (such as s3-bucket-public-read-prohibited) detects it right away, and auto remediation calls a Systems Manager Automation document to turn on Block Public Access for this bucket
Why use it
Records how resource configurations change and checks compliance automatically
What it is
Configuration recording and compliance checks: continuously records the configuration and change history of every resource in your account, and checks compliance with rules (for example, whether an S3 bucket is public or an EBS volume is encrypted). Noncompliant resources can be remediated automatically.
Common uses
Compliance auditing, finding out who broke a configuration, automatically making a public S3 bucket private again
Config service notes →

03EventBridgeRequired

Application Integration group · Serverless · By usage · Price $240
Role here
The compliance state change event is sent to EventBridge and forwarded to the security team (email or chat)
Why use it
Event senders and event handlers don't need to know each other: adding a handler doesn't require changing the sender, and it can also trigger on a schedule
What it is
Serverless event bus: routes events from Amazon Web Services services, your own applications and SaaS to Lambda, Step Functions and others by rule, and can also trigger on a schedule.
Common uses
Event-driven architectures, distributing events across accounts, scheduled tasks
