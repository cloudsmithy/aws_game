Bedrock

AI groupBilled per tokenPer tokenMulti-AZ built in

Call foundation models from multiple companies (Anthropic Claude, Amazon Nova, Meta Llama, Mistral, and more) through an API, billed per input and output token. Also includes Knowledge Bases, Agents, and Guardrails. Your data is not used to train models.

Disclaimer: The generative AI services from Amazon Web Services mentioned above are currently available in Amazon Web Services Regions outside mainland China. Cloud services in the Amazon Web Services China Regions are operated by NWCD and Sinnet; see the China Regions website for details.

Common uses

Chatbots, content generation, AI agents

Why use it

Choose it when you want to use ready-made large models directly: one API for models from many providers, no GPUs to manage, and you pay per token

Key concepts5 points

  1. Fully managed generative AI service: one API to call foundation models from many providers (Anthropic Claude, Amazon Nova, Meta Llama, Mistral, and more)
  2. Billed per input and output token; for heavy usage you can buy Provisioned Throughput
  3. Knowledge Bases handles RAG: documents in S3 are chunked, turned into vectors, and stored in a vector store (OpenSearch Serverless, Aurora PostgreSQL, and more)
  4. Guardrails filters harmful content and sensitive information; Agents can call tools and carry out multi-step tasks
  5. Your prompts and data are not used to train the foundation models

Correct 0 / 8, answered 0

1.What is Amazon Bedrock for?
AnswerA managed service that lets you call multiple foundation models through an API
Billed by input and output tokens; you can also buy Provisioned Throughput, which is billed by the hour
2.What are Bedrock Knowledge Bases mainly used for?
AnswerRetrieval-augmented generation (RAG)
Connects your own data to the model for retrieval augmentation
3.What does Bedrock cross-Region inference do?
AnswerSpreads requests across multiple Regions to handle traffic spikes
Geographic cross-Region inference only routes within a boundary such as the US or the EU, and global cross-Region inference routes worldwide for about 10% savings; if this Region has a problem, calls still won't go through
4.What is Bedrock Guardrails used for?
AnswerFiltering harmful content and masking sensitive information
Can be placed in front of different models and used consistently
5.Where is the data that users upload to Bedrock Knowledge Bases stored for retrieval?
AnswerA vector database, such as OpenSearch Serverless
The data is split into chunks, converted to vectors and stored; a question first retrieves, then generates
6.You have hundreds of thousands of product descriptions for a model to rewrite, and results within a few days are fine. Which Bedrock approach fits best?
AnswerBatch inference: submit a job and the results are written to S3
50% cheaper than on-demand, but completion time is not guaranteed; jobs time out after 24 hours by default, configurable up to 168 hours
7.Every call carries the same large system prompt and reference documents. Which Bedrock feature saves input cost and also reduces latency?
AnswerPrompt caching
Repeated long context is cached so later requests don't have to process it again; check the documentation for which models are supported
8.You want a smaller, cheaper model to come close to a large model's results in your own business scenario. What does Bedrock offer?
AnswerModel distillation: the large model acts as teacher to the small model
The large model generates synthetic data, which is then used to fine-tune the small model; afterward you call the small model, which is faster and cheaper
