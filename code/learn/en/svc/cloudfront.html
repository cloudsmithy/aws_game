CloudFront

Networking groupGlobal serviceBy usageGlobal service

CDN: caches your website, video and APIs at edge locations around the world so users connect to the nearest one, which takes load off the origin. Comes with Shield Standard against common DDoS attacks.

Common uses

Speeding up websites and static assets, video delivery

Why use it

Put it at the very front when users are spread out and there's a lot of static content: responses come from nearby, the origin carries less load, and attacks can be blocked at the edge

Key concepts5 points

  1. Global CDN: content is cached at edge locations so users connect to the nearest one; dynamic APIs can be accelerated through it too
  2. The origin can be S3 (with OAC so only CloudFront can read the private bucket), ALB, EC2, API Gateway, or any HTTP server
  3. Comes with Shield Standard against common DDoS attacks, and you can attach WAF too
  4. Edge compute: CloudFront Functions (lightweight, ultra-low latency) and Lambda@Edge (more capable)
  5. Signed URLs and signed cookies control access to private content; after you change content, you can send an invalidation request to refresh the cache

Compare and choose

CloudFront or ELB

For global users and lots of static content, attach Shield to CloudFront; for a single Region with mostly dynamic requests, attach it to ALB

1.What problem does CloudFront origin access control (OAC) solve?
AnswerLets only CloudFront read the S3 bucket, so the bucket doesn't need to be public
Supports more features than the older origin access identity (OAI)
2.What is CloudFront?
AnswerA CDN that caches content at edge locations close to users
Can also work with WAF and Shield to block attacks
3.What is a common cause of a low CloudFront cache hit ratio?
AnswerThe cache key includes extra request headers or query parameters
Use a cache policy to keep only the necessary keys
4.Which services can WAF be placed in front of?
AnswerCloudFront, ALB, API Gateway
WAF works at layer 7; on API Gateway it can only be attached to REST APIs, and it can also be attached to AppSync, Cognito user pools, and more
5.Users around the world find static assets slow to load. What is usually the first choice?
AnswerCloudFront
Edge locations cache content nearby, and origin fetches travel over the backbone network
6.A company uses Amazon CloudFront to distribute static website assets stored in an S3 bucket. Users must be able to access them only through CloudFront and not directly through the S3 object URL. What should it do?SAA-C03
AnswerConfigure origin access control (OAC), and have the bucket policy allow only that distribution to read
OAC lets CloudFront access S3 with signed requests, and together with a bucket policy that allows only that distribution, it blocks direct access. Public read access would make objects directly accessible; Transfer Acceleration speeds up transfers; versioning and MFA Delete protect against accidental deletion and don't control the read path. 7.A video website has users all over the world and wants to cache content such as images, JS, and videos at the location closest to users to reduce latency. Which service should it use?CLF-C02
AnswerAmazon CloudFront
CloudFront distributes content through edge locations around the world, and requests are routed to the edge location with the lowest latency. Direct Connect is a dedicated network connection and does not cache content. Official docs ↗
8.An online education company's origin is deployed in the US East Region. Static files such as cover images and JS/CSS are accessed frequently by students in Asia and Europe, and load slowly. How can global access performance be improved with the fewest changes?SAA-C03
AnswerUse Amazon CloudFront to cache the static content at edge locations
CloudFront caches content at edge locations around the world and routes requests to the edge location with the lowest latency. Self-managed servers in multiple Regions have high operating costs; changing the storage class affects only cost, not latency; larger origin instances cannot shorten the network distance across continents.
