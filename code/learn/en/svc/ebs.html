EBS

Storage groupIaaSBy the hourAlways single-AZ

Block storage for EC2 (cloud disks): a volume attaches to an instance in the same AZ as a system or data disk, and snapshots can be taken as backups. A volume lives in a single AZ.

Common uses

System disks, data disks for self-managed databases

Why use it

Use it when you need low-latency block storage that works like a local disk; snapshots are incremental backups

Key concepts5 points

  1. Block storage attached to EC2 in the same AZ, like a local disk; a volume lives in only one AZ, and moving to another AZ requires a snapshot
  2. Snapshots are incremental and stored in S3 (in a bucket you can't see); they can be copied across Regions and restored in another AZ or Region
  3. Volume types: gp3 (general purpose SSD, with performance and size configured separately), io2 Block Express (high-IOPS volumes for databases), st1 and sc1 (throughput-oriented HDD)
  4. Most volumes attach to only one instance at a time; io1 and io2 support Multi-Attach to multiple instances in the same AZ
  5. Encrypt with KMS, and you can turn on encryption by default for the account; Snapshot Lock keeps snapshots from being deleted until the lock expires

1.What is the biggest difference between EFS and EBS?
AnswerEFS can be mounted by multiple instances at once, while an EBS volume is generally attached to only one
EBS has Multi-Attach, but only for some volume types and within the same AZ
2.What scope does an EBS volume exist in?
AnswerA single AZ
So you need snapshots to recover in another AZ
3.What is the main advantage of EBS gp3 over gp2?
AnswerIOPS and throughput can be configured independently, and it costs less
gp2 performance is tied to capacity and relies on burst credits to peak; gp3 does not use burst credits
4.What do you still pay for after an EC2 instance is stopped?
AnswerEBS volume storage fees and Elastic IP fees
Stopping only stops compute charges; storage is still charged
5.A critical OLTP database running on a Nitro instance needs a single volume to sustain 200,000 IOPS with sub-millisecond latency. Which Amazon EBS volume type should it choose?SAA-C03
AnswerProvisioned IOPS SSD (io2 Block Express)
When attached to a Nitro instance, io2 Block Express can be provisioned with up to 256,000 IOPS per volume and provides consistent sub-millisecond latency. gp3 maxes out at 80,000 IOPS per volume; st1 and sc1 are HDDs built for sequential throughput and don't suit random-IOPS-intensive workloads.
