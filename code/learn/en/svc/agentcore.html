AgentCore

AI groupServerlessBy usageMulti-AZ built in

Bedrock AgentCore: a managed platform for taking AI agents to production. Runtime hosts and runs agents (frameworks such as LangGraph, CrewAI and Strands all work), each session runs in its own microVM, and you are billed for the compute actually used; components such as Memory, Gateway, Identity and Observability can be combined as needed.

Disclaimer: The generative AI services from Amazon Web Services mentioned above are currently available in Amazon Web Services Regions outside mainland China. Cloud services in the Amazon Web Services China Regions are operated by NWCD and Sinnet; see the China Regions website for details.

Common uses

Customer service assistants, operations assistants, AI assistants that can call business APIs

Why use it

The runtime isolation, session memory, tool gateway and identity that agents need in production are all managed, so you don't have to build them yourself

Key concepts4 points

  1. Amazon Bedrock AgentCore: a managed service for deploying agents to production and operating them; it works with any framework (Strands Agents, LangGraph, CrewAI, and more) and any model
  2. Runtime: a serverless runtime for agents that isolates each session and supports long-running tasks
  3. Memory handles short-term and long-term memory; Gateway turns existing APIs and Lambda functions into MCP tools that agents can call; Identity manages the identities and credentials agents use when accessing other services
  4. Also includes Code Interpreter (runs code in a sandbox), Browser (a managed browser), and Observability (tracing and monitoring)
