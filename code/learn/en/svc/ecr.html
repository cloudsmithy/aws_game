SERVICEContainers group · Managed

ECR

Containers groupManagedBy usageMulti-AZ built in

Managed container image registry: stores Docker and OCI images and can scan for vulnerabilities; ECS and EKS pull images directly from it.

Common uses

Push images here after a CI/CD build, and pull them at deployment

Why use it

Images sit right next to where they're deployed: permissions work directly with ECS and EKS, and images are scanned for vulnerabilities when you push them

Key concepts5 points

  1. A managed container image registry for Docker images and OCI artifacts (such as Helm charts)
  2. IAM controls who can push and who can pull; ECS, EKS, and Lambda (container image deployments) pull directly from here
  3. Image scanning: basic scanning, or enhanced scanning by Inspector, which keeps rescanning as new CVEs come out
  4. Lifecycle policies clean up old images automatically; images can be replicated across Regions and accounts
  5. Make tags immutable, and the same tag can't be overwritten by a new image
