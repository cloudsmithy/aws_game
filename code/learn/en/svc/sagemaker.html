SERVICEAI group · PaaS

SageMaker AI

AI groupPaaSBy the hourMulti-AZ is on you

Machine learning platform: prepare data, train, tune, and deploy models in one place. Includes managed notebook environments, and inference endpoints are billed by instance hours.

Common uses

Training your own models, deploying inference services

Why use it

Use it when you need to train, fine-tune or deploy models yourself: training, tuning, deployment and monitoring in one platform

Key concepts5 points

  1. Amazon SageMaker AI: a fully managed platform for building, training, and deploying machine learning models
  2. Training: managed training jobs; Spot training saves money, and distributed training is supported
  3. Deployment: real-time inference endpoints, Serverless inference, asynchronous inference, and batch transform
  4. JumpStart provides pretrained models and ready-made solutions, and can deploy open source large language models in one click
  5. Training data usually lives in S3, and your own training and inference images go in ECR

Three key featuresThe game's three upgrade levels are these three real-world features

LV.1 · Level 1

Multi-AZ inference endpoints

Inference instances are spread across multiple AZs

In the game: Survives an AZ power outage and single points of failure

Running cost: $20 per lap

LV.2 · Level 2

Multi-GPU training (GPU cluster)

Reserve a batch of GPUs with a training plan first, then train in parallel on multiple GPUs for bigger models and faster training

In the game: Immune to “not enough GPU capacity” (GenAI Wave DLC); Rent on this square +20%

Running cost: $30 per lap

LV.3 · Level 3

Train your own large model (HyperPod)

Trains your own foundation model on a HyperPod cluster, with bad nodes replaced automatically

In the game: Higher rent

Running cost: $40 per lap

Compare and choose

Bedrock or SageMaker AI

To use ready-made large models directly (Claude, Nova, Llama and more), choose Bedrock and pay per token; to train, fine-tune or deploy open-source models yourself, choose SageMaker AI

1.What is it called when SageMaker AI deploys a model as a real-time inference service?
AnswerEndpoint
Also supports asynchronous inference and batch transform
2.With the default configuration, is a SageMaker AI real-time inference endpoint charged when it has no traffic?
AnswerYes, the instance stays running
Billed by instance-hour. For low traffic you can use Serverless or asynchronous inference; an endpoint with managed inference components can also scale down to 0 instances
3.What is SageMaker HyperPod mainly used for?
AnswerLarge-scale distributed training, with failed nodes replaced automatically
Training a foundation model can take weeks, so automatic recovery from node failures matters
4.A data scientist works in Amazon SageMaker Studio and wants to browse pre-trained models from the various model hubs and fine-tune, deploy, or evaluate a selected model directly. Which feature should be used?AIF-C01
AnswerAmazon SageMaker JumpStart
JumpStart provides a large number of pre-trained models, solution templates, and example notebooks, and lets you fine-tune, deploy, and evaluate models from the Models page in Studio. Model Monitor is for production monitoring, Clarify is for bias and explainability, and Ground Truth is for data labeling. Official docs ↗
5.A company needs to score a very large dataset with a trained model every night, and needs no online predictions during the day. With Amazon SageMaker AI, which inference option is the best fit?AIF-C01
AnswerBatch transform, with no persistent inference endpoint required
The official documentation says batch transform suits running inference on large datasets when a persistent endpoint is not needed; real-time inference is for workloads that need low-latency interactive responses. Official docs ↗
6.A financial company is developing a loan approval model. It needs both to check whether the training data has noticeably few samples for certain groups and to explain how much each feature contributes to a single prediction. Which Amazon Web Services tool provides both of these capabilities?AIF-C01
AnswerAmazon SageMaker Clarify
Clarify can compute pre-training bias metrics (such as class imbalance, CI) and give feature attributions based on Shapley values to explain predictions. Note: the official documentation shows that Clarify is no longer open to new customers; existing customers can continue to use it. Official docs ↗
7.For a credit scoring model that is already live, the team worries that as online data changes, the model's predictions will gradually develop bias drift and its accuracy will drop, and wants an automatic alert when it deviates. Which feature should be used?AIF-C01
AnswerAmazon SageMaker Model Monitor
Model Monitor continuously monitors production models for data quality, model quality, bias drift, and feature attribution drift, and sends an alert when deviations appear. Note: the official documentation shows that Model Monitor is no longer open to new customers; existing customers can continue to use it. Official docs ↗
