Service notes/Networking group/ELB

SERVICENetworking group · Managed

ELB

Networking groupManagedBy the hourMulti-AZ built in

Load balancing: spreads traffic across multiple EC2 instances, containers or Lambda functions behind it and automatically routes around unhealthy ones; ALB handles HTTP/HTTPS and NLB handles TCP/UDP.

Common uses

A single entry point for websites and APIs, Multi-AZ high availability

Why use it

One entry point in front of multiple backends: it spreads traffic automatically, routes around failed instances, and spans AZs by design

Key concepts5 points

  1. Three main types: ALB (layer 7, routes HTTP and HTTPS by path and host name), NLB (layer 4 TCP and UDP, low latency, can provide static IPs), and GWLB (puts third-party security appliances inline)
  2. Health checks automatically move traffic away from unhealthy targets; the load balancer itself spans multiple AZs
  3. ALB can use WAF, integrate with Cognito for sign-in, and offload TLS (with free certificates from ACM)
  4. Works with Auto Scaling groups: newly launched instances register with the target group automatically
  5. Billed by the hour plus Load Balancer Capacity Units (LCU)

Compare and choose

CloudFront or ELB

For global users and lots of static content, attach Shield to CloudFront; for a single Region with mostly dynamic requests, attach it to ALB

1.Which layer does an ALB work at?
AnswerLayer 7 (HTTP/HTTPS)
ALB is layer 7 and NLB is layer 4
2.Which services can WAF be placed in front of?
AnswerCloudFront, ALB, API Gateway
WAF works at layer 7; on API Gateway it can only be attached to REST APIs, and it can also be attached to AppSync, Cognito user pools, and more
3.A public-facing website is deployed behind an Application Load Balancer. Recently, a few IP addresses were found sending large numbers of HTTP requests in a short time to hammer the API. How can these IPs be restricted automatically with the least operational effort?SAA-C03
AnswerAssociate a WAF web ACL with the ALB and add a rate-based rule
A WAF rate-based rule counts requests by dimensions such as IP and automatically throttles them when the threshold is exceeded, with no need to maintain a list by hand. Security groups only support allow rules; an NLB works at layer 4 and can't detect abuse at the HTTP layer; manually analyzing flow logs and then editing the network ACL is slow and costs a lot of operational effort. 4.A web application runs on 3 EC2 instances in a single Availability Zone behind an ALB. At one point the application process hung while the EC2 status checks were still normal, causing some requests to fail. How can you both improve Availability Zone-level resilience and automatically replace unhealthy instances?SAA-C03
AnswerAn Auto Scaling group across multiple Availability Zones with ELB health checks enabled
An Auto Scaling group across multiple Availability Zones maintains capacity if one Availability Zone fails; with ELB health checks enabled, instances that are unhealthy at the application layer are also replaced automatically. Larger instances don't remove the single-AZ risk; EC2 status checks can't detect application-layer failures, and an alarm alone still needs manual handling; simple routing doesn't perform health checks. Official docs ↗
5.A company splits a monolithic application into multiple microservices and wants to use one domain name to forward HTTP requests to different target groups based on the URL path (such as /api/orders and /api/users). Which type of load balancer should it use?SAA-C03
AnswerAn Application Load Balancer, with listener rules that use path conditions
An ALB works at layer 7, and its listener rules support path-pattern conditions, so it can route to different target groups by URL path. An NLB works at layer 4 and can't see the URL path; a Gateway Load Balancer is for deploying third-party virtual network appliances; multiple CLBs and domain names don't meet the single-domain requirement. Official docs ↗
6.A real-time multiplayer game uses a custom UDP protocol, needs to handle millions of requests per second with extremely low latency, and needs a fixed IP address per Availability Zone so customers can add it to firewall allow lists. Which type of load balancer should it choose?SAA-C03
AnswerA Network Load Balancer, with one Elastic IP associated with each subnet
An NLB works at layer 4, supports UDP, can handle millions of requests per second, and provides a static IP for each Availability Zone, and for internet-facing use you can associate an Elastic IP. An ALB is for HTTP/HTTPS and does not support UDP; a CLB supports only HTTP, HTTPS, TCP, and SSL; manually registered instance IPs can't update automatically as the fleet scales. Official docs ↗
7.An operations team wants to describe resources such as EC2, load balancers, and databases in one template, then recreate the same environment with one click (infrastructure as code). Which service should they use?CLF-C02
AnswerCloudFormation
CloudFormation lets you describe the resources you need in a template, and it provisions and configures them for you. The resulting collection of resources is called a stack. Cost Explorer is used to analyze costs and cannot create resources. Official docs ↗
