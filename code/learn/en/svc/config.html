Config

Monitoring groupBy usageBy usageWildcard service

Configuration recording and compliance checks: continuously records the configuration and change history of every resource in your account, and checks compliance with rules (for example, whether an S3 bucket is public or an EBS volume is encrypted). Noncompliant resources can be remediated automatically.

Common uses

Compliance auditing, finding out who broke a configuration, automatically making a public S3 bucket private again

Why use it

Records how resource configurations change and checks compliance automatically

Key concepts5 points

  1. Records resource configurations and their change history: when a security group was changed, by whom, and to what
  2. Config rules (managed or custom) continuously check whether resources are compliant, for example “S3 buckets must not be public” and “EBS volumes must be encrypted”
  3. Non-compliant resources can be remediated automatically (by running Systems Manager Automation documents)
  4. Conformance packs bundle a set of rules for deployment; aggregators collect compliance status across multiple accounts and Regions
  5. Billed by the number of configuration items recorded and the number of rule evaluations

Three key featuresThe game's three upgrade levels are these three real-world features

LV.1 · Level 1

Managed rules

Uses managed rules to continuously check whether resource configurations are compliant, such as whether an S3 bucket is public or an EBS volume is unencrypted

In the game: Immune to “Failed security audit”

Running cost: 15% request fees each time rent is received

LV.2 · Level 2

Auto remediation

Non-compliant resources are fixed automatically with Systems Manager Automation documents, for example setting a public S3 bucket back to private

In the game: Immune to “someone manually changed the production config”; Immune to “S3 bucket made public”

Running cost: 15% request fees each time rent is received

LV.3 · Level 3

Aggregators

Collects configuration and compliance results from multiple accounts and Regions into one place

In the game: Higher rent

Running cost: 15% request fees each time rent is received
