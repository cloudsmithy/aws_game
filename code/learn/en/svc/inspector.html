Inspector

Security groupManagedBy usageMulti-AZ built in

Automated vulnerability scanning: continuously scans EC2 instances, container images in ECR, and Lambda functions for software vulnerabilities and unintended network exposure, and scores them by risk.

Common uses

Patch management, compliance checks

Why use it

Finds vulnerabilities in EC2, container images and Lambda automatically, so when a new CVE comes out, you don't have to wait for someone to run a scan

Key concepts5 points

  1. Automated, continuous vulnerability management: scans EC2, ECR container images, and Lambda functions for software vulnerabilities (CVEs) and network exposure
  2. When a new CVE is published or a software package changes, it reassesses automatically, with no need for scheduled manual scans
  3. Risk scores combine vulnerability severity with actual exposure, so you fix the most urgent issues first
  4. EC2 scanning uses the SSM Agent, or it can be agentless (based on EBS snapshots)
  5. Findings can be aggregated in Security Hub and sent to EventBridge; you can export a software bill of materials (SBOM)
