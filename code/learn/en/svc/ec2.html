SERVICECompute group · IaaS

EC2

Compute groupIaaSBy the hourMulti-AZ is on you

Virtual servers in the cloud: you pick CPU, memory and operating system, billed by the second, and you can buy them On-Demand, with Savings Plans, as Spot and more. Each instance lives in one AZ, so for high availability you place several in multiple AZs, together with ELB and Auto Scaling.

Common uses

Running all kinds of applications, cases that need full control of the operating system

Why use it

Use it when you need full control of the operating system, special software or legacy apps; it has the widest range of instance types

Key concepts5 points

  1. Virtual servers, with CPU, memory, and networking chosen by instance type: general purpose (M), compute optimized (C), memory optimized (R), GPU instances (P and G), and more
  2. Purchase options: On-Demand, Savings Plans, Reserved Instances, Spot (uses spare capacity, saves up to 90%, with a two-minute warning before it's reclaimed), and Dedicated Hosts
  3. An instance lives in a single AZ; high availability comes from an Auto Scaling group spanning multiple AZs plus a load balancer
  4. Security groups are instance-level, stateful firewalls; use an IAM role (instance profile) to access cloud services, and don't put access keys on the machine
  5. Data on the instance store is lost when the instance stops; keep the data you need on EBS

Three key featuresThe game's three upgrade levels are these three real-world features

LV.1 · Level 1

Auto AMI

Uses Data Lifecycle Manager to create AMIs of instances (with their attached EBS volumes) on a schedule; if an instance breaks or is deleted by mistake, launch another one from the image

In the game: Immune to accidental data deletion

Running cost: $15 per lap

LV.2 · Level 2

Cross-AZ Auto Scaling

An Auto Scaling group spreads instances across several AZs and scales in and out by CPU or request count; if one AZ has a problem, instances in the other AZs take over

In the game: Immune to “EC2 instance hardware retirement”; Survives an AZ power outage and single points of failure; Survives traffic surges

Running cost: $25 per lap

LV.3 · Level 3

Graviton

Switches to Arm-based instances, which are cheaper for the same performance

In the game: Running cost or request fees halved

Running cost: $20 per lap

Compare and choose

EC2 or ECS

For full control of the operating system or legacy apps, use EC2; if you're already containerized and want less to manage, use ECS (with Fargate you don't even manage machines)

EC2 or ECS or EKS

For full control of the operating system, use EC2; for containers with less to manage, use ECS; if your team knows Kubernetes, choose EKS

AnswerFree

AnswerTheir own data and permissions, and system patches when using EC2
