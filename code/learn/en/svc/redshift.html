SERVICEAnalytics group · PaaS

Redshift

Analytics groupPaaSBy the hourMulti-AZ is on you

Cloud data warehouse: columnar storage and massively parallel processing, analyzing huge amounts of data with SQL; available as provisioned clusters or Redshift Serverless.

Common uses

BI reports and business analytics

Why use it

Use it for large data volumes with lots of reports and complex SQL: columnar storage plus massively parallel processing can query billions of rows

Key concepts5 points

  1. Cloud data warehouse: columnar storage plus massively parallel processing (MPP), suited to complex SQL analytics and reporting
  2. Two options: provisioned clusters (RA3 nodes, which scale compute and storage separately) and Redshift Serverless (billed by usage)
  3. Redshift Spectrum queries data in S3 directly; Zero-ETL integrations sync data from Aurora, RDS, and DynamoDB in near real time
  4. Streaming ingestion reads data directly from Kinesis and MSK
  5. Data sharing lets multiple clusters use the same data without copying it back and forth

Compare and choose

OpenSearch or Redshift

For full-text search and real-time log search, choose OpenSearch; for large-scale SQL analytics and reports, choose Redshift

OpenSearch or Redshift or S3

For cheap long-term storage and offline analysis, use an S3 data lake; for SQL reports in seconds, load the data into Redshift; for real-time search, load it into OpenSearch
