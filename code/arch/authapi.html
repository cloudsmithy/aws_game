每一块干什么5 块服务

01Cognito必须

安全组 · 托管服务 · 按用量 · 售价 $80
在这里
Cognito 授权方先验令牌
为什么用它
登录这件事不用自己写：密码存储、MFA、找回密码、社交登录都是现成的，还能直接给 API Gateway 和 ALB 做鉴权
它是什么
给你的 App 和网站管用户登录：用户池存账号，负责注册、登录、MFA，登录后发 JWT 令牌；身份池把登录的用户换成临时的亚马逊云科技凭证，App 可以直接访问 S3 这类服务。按月活跃用户（MAU）计费。
常见用法
App 和网站的注册登录、给 API 加登录校验（API Gateway、ALB 都能直接认 Cognito 的令牌）、手机 App 直传文件到 S3

02API Gateway必须

网络组 · Serverless · 按用量 · 售价 $220
在这里
请求带着令牌打到 API Gateway
为什么用它
不用自己搭网关：鉴权、限流、缓存、版本管理开箱就有，后面直接接 Lambda
它是什么
托管的 API 入口：创建 REST、HTTP、WebSocket API，负责鉴权、限流和缓存，后面接 Lambda 或其他服务，按调用次数收费。
常见用法
Serverless API、移动应用和小程序后端
API Gateway 的知识点 →

03Lambda必须

计算组 · Serverless · 按用量 · 售价 $220
在这里
验过的请求才转给 Lambda
为什么用它
代码不多、按事件触发的活交给它：不用管服务器和扩容，没请求就不花钱
它是什么
无服务器函数：上传代码，有事件来才运行，按请求次数和运行时长（毫秒）收费，没请求不收钱；单次最长运行 15 分钟。
常见用法
API 后端、处理 S3 上传的文件、定时任务

04DynamoDB可选几选一

数据库组 · Serverless · 按用量 · 售价 $240
在这里
读写 DynamoDB 或 Aurora
为什么用它
访问方式固定、并发特别高时用它：没有数据库服务器要管，读写延迟稳定在毫秒级
它是什么
Serverless 的键值和文档数据库：毫秒级读写，按需模式按请求收费，数据自动存在多个 AZ；全局表可以多区域同时读写。
常见用法
用户会话、购物车、游戏数据、高并发场景
DynamoDB 的知识点 →

04Aurora可选几选一

数据库组 · PaaS · 按小时 · 售价 $280
在这里
读写 DynamoDB 或 Aurora
为什么用它
要更高性能和可用性的 MySQL、PostgreSQL 时选它：存储自动跨 3 个 AZ，只读副本延迟低
它是什么
亚马逊云科技自研的云原生关系数据库，兼容 MySQL 和 PostgreSQL：数据在 3 个 AZ 里存 6 份，最多 15 个只读副本；Aurora Serverless v2 按负载自动伸缩，Global Database 能跨区域。
常见用法
高并发的核心业务数据库
Aurora 的知识点 →
这一环怎么选

按键读写、并发特别高、访问方式固定，选 DynamoDB；要 SQL、事务、多表关联，选 Aurora（Serverless v2 会自动扩缩）
