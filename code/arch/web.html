每一块干什么4 块服务

01Route 53必须

网络组 · 全局服务 · 按用量 · 售价 $160
在这里
Route 53 解析域名
为什么用它
域名解析和健康检查一起做：一边挂了自动切到另一边
它是什么
托管的 DNS：注册和解析域名，能按健康检查做故障切换，按延迟或地理位置把用户引到不同区域。全局服务，可用性 SLA 是 100%。
常见用法
域名解析、跨区域容灾切换
Route 53 的知识点 →

02CloudFront必须

网络组 · 全局服务 · 按用量 · 售价 $400
在这里
CloudFront 全球缓存
为什么用它
用户分布广、静态内容多时放在最前面：就近返回，源站压力小，还能在边缘挡攻击
它是什么
CDN：把网站、视频和 API 缓存到全球各地的边缘站点，用户就近访问，减轻源站压力；自带 Shield Standard 挡常见的 DDoS。
常见用法
网站和静态资源加速、视频分发
CloudFront 的知识点 →

03WAF可选

安全组 · 托管服务 · 按用量 · 售价 $400
在这里
WAF 挡掉恶意请求
为什么用它
在入口按规则拦 SQL 注入、XSS、恶意爬虫和刷接口，不用改应用代码
它是什么
Web 应用防火墙：挂在 CloudFront、ALB、API Gateway 前面，按规则拦 SQL 注入、跨站脚本和恶意机器人，还能按 IP 限速。
常见用法
防常见 Web 攻击、防刷接口
WAF 的知识点 →

04S3必须

存储组 · Serverless · 按用量 · 售价 $60
在这里
S3 存网页文件
为什么用它
不用规划容量，存多少付多少，数据持久性 11 个 9；越放越冷的数据还能自动转到更便宜的存储类别
它是什么
对象存储：文件当成「对象」放进桶里，按存的数据量和请求次数收费，容量不用提前规划。标准存储类会把数据存到一个区域里至少 3 个 AZ。
常见用法
网站图片和静态资源、数据湖、备份归档、日志
