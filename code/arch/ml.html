每一块干什么4 块服务

01S3必须几选一

存储组 · Serverless · 按用量 · 售价 $60
在这里
训练数据放 S3 或 EFS
为什么用它
不用规划容量，存多少付多少，数据持久性 11 个 9；越放越冷的数据还能自动转到更便宜的存储类别
它是什么
对象存储：文件当成「对象」放进桶里，按存的数据量和请求次数收费，容量不用提前规划。标准存储类会把数据存到一个区域里至少 3 个 AZ。
常见用法
网站图片和静态资源、数据湖、备份归档、日志
S3 的知识点 →

01EFS必须几选一

存储组 · Serverless · 按用量 · 售价 $100
在这里
训练数据放 S3 或 EFS
为什么用它
多台机器要读写同一批文件时，不用自己搭 NFS 服务器，容量随用随长
它是什么
托管的共享文件系统（NFS）：多台 EC2、容器、Lambda 能同时挂载同一个目录，容量随写随涨，按用了多少收费。
常见用法
多台服务器共用的文件、内容管理、机器学习训练数据
EFS 的知识点 →
这一环怎么选

训练数据量大、按文件整块读，放 S3（便宜）；多台机器要像本地磁盘一样共享读写，用 EFS

02ECR必须

容器组 · 托管服务 · 按用量 · 售价 $180
在这里
自己的训练镜像放 ECR
为什么用它
镜像就放在部署的地方旁边：和 ECS、EKS 权限打通，推送时顺手扫漏洞
它是什么
托管的容器镜像仓库：存放 Docker / OCI 镜像，可以扫描漏洞，ECS、EKS 直接从这里拉镜像。
常见用法
CI/CD 构建完镜像推上去，部署时拉下来
ECR 的知识点 →

03SageMaker AI必须

AI组 · PaaS · 按小时 · 售价 $460
在这里
SageMaker AI 拉镜像、读数据
为什么用它
要自己训练、微调或部署模型时用它：训练、调参、上线、监控在一个平台里
它是什么
机器学习平台：在上面准备数据、训练、调参和部署模型，有托管的 Notebook 环境，推理端点按实例时长收费。
常见用法
训练自己的模型、部署推理服务
