每一块干什么4 块服务

01CloudFront必须几选一

网络组 · 全局服务 · 按用量 · 售价 $400
在这里
CloudFront 分发或 ALB 加进 Shield Advanced 保护
为什么用它
用户分布广、静态内容多时放在最前面：就近返回，源站压力小，还能在边缘挡攻击
它是什么
CDN：把网站、视频和 API 缓存到全球各地的边缘站点，用户就近访问，减轻源站压力；自带 Shield Standard 挡常见的 DDoS。
常见用法
网站和静态资源加速、视频分发
CloudFront 的知识点 →

01ELB必须几选一

网络组 · 托管服务 · 按小时 · 售价 $140
在这里
CloudFront 分发或 ALB 加进 Shield Advanced 保护
为什么用它
多台后端前面放一个统一入口：自动分流量、绕开坏掉的实例，天生跨 AZ
它是什么
负载均衡：把流量分给后面多台 EC2、容器或 Lambda，自动绕开不健康的；ALB 处理 HTTP/HTTPS，NLB 处理 TCP/UDP。
常见用法
网站和 API 的统一入口、多 AZ 高可用
ELB 的知识点 →
这一环怎么选

全球用户、静态内容多，Shield 挂在 CloudFront 上；只在一个区域、动态请求为主，挂在 ALB 上

02Shield Advanced必须

安全组 · 全局服务 · 订阅 · 售价 $420
在这里
CloudFront 分发或 ALB 加进 Shield Advanced 保护
为什么用它
扛大流量 DDoS：有专家团队 7×24 小时响应，攻击期间多出来的扩容费用能申请抵扣
它是什么
DDoS 防护：所有账户都免费带 Shield Standard，挡常见的网络层攻击；Shield Advanced 是付费订阅，加上应用层防护、DDoS 响应团队支持和攻击期间扩容费用补偿。
常见用法
对 DDoS 敏感的大型网站、游戏、金融业务
Shield Advanced 的知识点 →

03WAF必须

安全组 · 托管服务 · 按用量 · 售价 $400
在这里
防应用层攻击要给这个入口关联 WAF Web ACL
为什么用它
在入口按规则拦 SQL 注入、XSS、恶意爬虫和刷接口，不用改应用代码
它是什么
Web 应用防火墙：挂在 CloudFront、ALB、API Gateway 前面，按规则拦 SQL 注入、跨站脚本和恶意机器人，还能按 IP 限速。
常见用法
防常见 Web 攻击、防刷接口

在游戏里怎么算

必须的
3 块：CloudFront 或 ELB、Shield Advanced、WAF
怎么收
凑齐以后，别人落在这套里你的任意一块，按整套架构所有服务的过路费加起来收；「或」的几块都在你手上就都算进来
大概多少
按没升级、骰子 7 点估：最省的凑法每次约 $192，每一环都配满（最优架构）约 $272；升级以后还会高很多
额外加成
WAF 不交每圈的固定费用，升「托管规则」「限速规则」半价：Shield Advanced 订阅包了受保护资源上 WAF 的标准费用（Bot Control 不在里面，照原价）
