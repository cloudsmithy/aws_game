每一块干什么

1. S3必须

存储组 · Serverless · 按用量 · 游戏里售价 $60
在这里干什么
原始数据落 S3
为什么用它
不用规划容量，存多少付多少，数据持久性 11 个 9；越放越冷的数据还能自动转到更便宜的存储类别
它是什么
对象存储：文件当成「对象」放进桶里，按存的数据量和请求次数收费，容量不用提前规划。标准存储类会把数据存到一个区域里至少 3 个 AZ。
常见用法
网站图片和静态资源、数据湖、备份归档、日志
S3 的知识点 →

2. Glue必须

分析组 · Serverless · 按用量 · 游戏里售价 $300
在这里干什么
Glue 作业清洗转换
为什么用它
清洗数据、转格式、建数据目录不用自己搭集群，按运行时间付费
它是什么
Serverless 的数据集成（ETL）服务：爬取数据源建数据目录，用 Spark 作业清洗、转换数据，按运行时长收费。
常见用法
数据湖入湖、给 Athena 和 Redshift 准备数据
Glue 的知识点 →

3. Redshift必须

分析组 · PaaS · 按小时 · 游戏里售价 $340
在这里干什么
加载进 Redshift 做报表和 BI 分析
为什么用它
数据量大、报表和复杂 SQL 多时用它：列式存储加大规模并行，几十亿行也查得动
它是什么
云数据仓库：列式存储、大规模并行处理，用 SQL 分析海量数据；有预置集群和 Redshift Serverless 两种用法。
常见用法
BI 报表、经营分析

在游戏里怎么算

  • 必须的 3 块：S3、Glue、Redshift。
  • 凑齐以后，别人落在这套里你的任意一块，按整套架构所有服务的过路费加起来收；「或」的几块都在你手上就都算进来。
  • 按没升级、骰子 7 点估：最省的凑法每次约收 $140，每一环都配满（最优架构）约 $140；升级以后还会高很多。
