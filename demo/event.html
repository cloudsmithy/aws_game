每一块干什么

1. EventBridge必须

应用集成组 · Serverless · 按用量 · 游戏里售价 $240
在这里干什么
EventBridge 收事件
为什么用它
发事件的和处理事件的互不认识：多加一个处理方不用改发送方，还能按时间表触发
它是什么
Serverless 事件总线：把亚马逊云科技服务、自己的应用和 SaaS 发出的事件按规则转给 Lambda、Step Functions 等，也能定时触发。
常见用法
事件驱动架构、跨账户分发事件、定时任务
EventBridge 的知识点 →

2. Step Functions必须

应用集成组 · Serverless · 按用量 · 游戏里售价 $260
在这里干什么
Step Functions 编排
为什么用它
多步骤的流程不用自己写状态机：每一步的重试、超时、失败回滚都能配，执行到哪一步看得见
它是什么
可视化的工作流编排：把 Lambda、容器任务和各种服务的 API 调用串成状态机，自带重试、分支、并行，还能停下来等人工审批。
常见用法
订单处理流程、数据处理流水线、编排 AI Agent 的步骤
Step Functions 的知识点 →

3. Lambda必须

计算组 · Serverless · 按用量 · 游戏里售价 $220
在这里干什么
Lambda 执行每一步
为什么用它
代码不多、按事件触发的活交给它：不用管服务器和扩容，没请求就不花钱
它是什么
无服务器函数：上传代码，有事件来才运行，按请求次数和运行时长（毫秒）收费，没请求不收钱；单次最长运行 15 分钟。
常见用法
API 后端、处理 S3 上传的文件、定时任务

在游戏里怎么算

  • 必须的 3 块：EventBridge、Step Functions、Lambda。
  • 凑齐以后，别人落在这套里你的任意一块，按整套架构所有服务的过路费加起来收；「或」的几块都在你手上就都算进来。
  • 按没升级、骰子 7 点估：最省的凑法每次约收 $144，每一环都配满（最优架构）约 $144；升级以后还会高很多。
